PART 3 — FIND THE EXACT GLOBAL BREAKPOINT
====================================================

Classify the failure as one of these:

A. Selected symbol issue
- scanner symbol is undefined/null
- display name not mapped to backend symbol
- V75/Volatility naming mismatch
- symbol dropdown value not compatible with candle endpoint
- selected market state not passed to chart

B. Timeframe issue
- timeframe undefined
- timeframe format mismatch
- endpoint expects M1 but frontend sends 1m
- provider rejects certain timeframe
- recent timeframe tabs broke query

C. Frontend request issue
- hook not called
- query disabled
- query key wrong
- cache stuck on unavailable
- missing dependency
- auth issue
- wrong endpoint path
- SSE/live snapshot hook accidentally replacing candle hook
- stale/error state swallowed

D. Backend endpoint issue
- endpoint returns empty for all
- auth/session issue
- provider not reached
- provider throws but endpoint hides error
- response shape changed
- source/freshness gate rejects all candles

E. Provider/feed issue
- MT5 candle store empty
- Deriv feed unavailable
- third-party/historical provider disabled
- updateCandlesFromMT5 not called
- EA quote push exists but candle push missing
- provider ignores timeframe
- no true candle feed exists

F. Adapter/formatter issue
- response has candles but frontend expects data
- timestamp parse failure
- numeric conversion failure
- all candles filtered as invalid/stale
- source tag mismatch
- required fields missing: open/high/low/close/time

G. Render guard issue
- chart has data but guard says feed unavailable
- handshake result blocks chart incorrectly
- analysis-only state forced globally
- stale state treated as no data
- chart waits for Ruby signal/news/snapshot before rendering

H. CSS/container issue
- unlikely because empty state is visible, but still check if data exists and chart is hidden

Identify the exact category and evidence.
