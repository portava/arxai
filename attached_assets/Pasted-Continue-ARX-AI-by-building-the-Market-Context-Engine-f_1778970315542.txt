PART 1 — Market Data Context Layer

Create a Market Context service that can build context for any symbol tied to an open trade.

Use available data sources:
1. MT5 candles if available.
2. MT5 ticks/current bid/ask if available.
3. Existing scanner data.
4. Existing market data provider if available.
5. Economic/news calendar only if already available.
6. If none exists, return data_quality: insufficient.

For each symbol, gather:
- current price
- bid/ask
- spread
- recent candles
- volume/tick volume if available
- volatility
- ATR if available
- session context
- trend by timeframe
- key highs/lows
- support/resistance zones
- breakout levels
- recent swing high/swing low
- current range
- distance to stop loss
- distance to take profit
- distance to entry
- data freshness timestamp

Timeframes:
- M1
- M5
- M15
- M30
- H1
- H4
- D1 if available

If not all timeframes are available, use what exists and clearly label missing data.

PART 3 — Trade-Specific Market Context

For every open trade, compare the trade direction against the market context.

For BUY trades, check:
- Is price holding above entry?
- Is higher-timeframe trend aligned?
- Are pullbacks respecting higher lows?
- Is price rejecting resistance?
- Is profit fading after a failed push?
- Has price broken bullish structure?

For SELL trades, check:
- Is price holding below entry?
- Is higher-timeframe trend aligned?
- Are pullbacks respecting lower highs?
- Is price rejecting support?
- Is profit fading after a failed drop?
- Has price broken bearish structure?

Add trade labels:
- Trade aligned with trend
- Trade fighting trend
- Trade still valid
- Trade weakening
- Trade invalidation near
- Trade at decision level
- Profit protection needed
- Exit review recommended
