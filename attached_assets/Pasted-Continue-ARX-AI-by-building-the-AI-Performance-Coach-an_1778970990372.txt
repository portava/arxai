Journal entry should include:
- user_id
- trade_id
- symbol
- side
- account type: demo/live
- routing mode: user-owned/shared-master
- open time
- close time
- entry price
- exit price
- lot size
- realized P&L
- pips/points
- win/loss/breakeven
- session
- trade duration
- max favorable excursion
- max adverse excursion
- peak profit
- profit giveback
- stop loss / take profit if available
- exit reason
- AI alerts fired
- AI decision before close
- user action taken
- whether user ignored alerts
- risk profile at time of trade
- position size/risk data if available
- broker rejection/errors if any

If data is missing, show unavailable instead of fake values.
