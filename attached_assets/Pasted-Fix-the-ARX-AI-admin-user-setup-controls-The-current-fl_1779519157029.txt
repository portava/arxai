Fix the ARX AI admin/user setup controls. The current flow is still too buggy, too complicated, and too technical.

MAIN GOAL:
Admin should control user access and platform access with simple ON/OFF switches throughout the website. Do not require typing confirmation phrases anywhere.

CURRENT PROBLEMS FROM SCREENSHOTS:
- Manage Access controls are complicated.
- Some switches do not work.
- Admin has to type phrases like ENABLE LIVE TRADING, DISABLE USER, or APPROVE SHARED BRIDGE.
- Live Shared Account tabs overlap badly on mobile.
- Internal/backend labels are exposed, including:
  - ARX_LIVE_BROKER_EXECUTION_ENABLED
  - platformMode=DEMO
  - routing=USER_OWNED
  - sharedLiveTradingEnabled
  - masterBridgeLiveEnabled
  - arx_live_commands
  - POST /api/admin/master-bridge/snapshot
- Admin sees technical architecture instructions that should not be in the main UI.
- Admin controls are spread across confusing pages.
- Bottom nav and Ruby bubble cover controls/content.
- Toggle buttons look active but do not reliably save or update state.

REQUIREMENTS:

1. REPLACE TYPED CONFIRMATIONS WITH SWITCHES
Remove all typed confirmation phrase requirements from admin/user setup.

Replace typed confirmations with:
- Toggle switch
- Clear confirmation modal for dangerous actions
- Confirm button
- Cancel button

Do NOT make admin type phrases.

Dangerous actions that still need a confirmation modal:
- Enable Live Trading
- Enable Shared/Master Bridge
- Disable User
- Suspend User
- Release Kill Switch
- Increase max lot size
- Increase max daily loss
- Enable AI auto-close
- Enable broker execution

The modal should say clearly what will happen, but the admin should only tap Confirm or Cancel.

2. FIX ALL SWITCHES
Audit every switch/toggle across the app and make sure each one:
- Updates visually immediately
- Saves to backend/database
- Refreshes correctly after page reload
- Shows success or failure
- Rolls back visually if save fails
- Is disabled only when there is a real reason
- Has a clear friendly reason if disabled

Fix broken switches in:
- Manage Access
- Account Access
- Trading Access
- Bridge Access
- Ruby / AI Access
- Scanner Access
- Risk Limits
- Push Settings
- Live Shared Account
- Kill Switches
- Broker Execution
- User Permissions
- Any other admin/operator access page
