Build II = Trader Coach + Playbook Generator.

Goal:
Create a Trader Coach system that reads the trading calendar, AI decisions, paper trades, debriefs, learning events, mistake patterns, strategy edges, autopilot history, and Risk Governor status, then turns that data into clear coaching instructions and a living playbook.

The coach should answer:
- What should I improve today?
- What mistakes keep repeating?

- What should be in my trading playbook?

- What is my weekly improvement plan?

3. Create coaching logic

The coach should generate guidance from data:

If repeated losses:
- recommend pause/review
- identify mistake pattern
- add cooldown or checklist rule
- recommend paper-only observation

If high-risk decisions:
- recommend risk reduction
- add rule about skipping high risk_score trades
- highlight examples from recent trades

If wide-spread/stale-data blocks:
- recommend avoiding bad market conditions
- add market quality checklist item

If same-symbol overexposure:
- recommend max same-symbol rule
- remind user about cooldowns

If learning confidence is low:
- recommend more paper sample size
- do not exaggerate confidence
- clearly say data is still early

If setup is performing well:
- convert into playbook entry
- identify symbol, timeframe, signal combination, risk profile, and best conditions

If setup is performing poorly:
- mark as avoid/review
- identify failure pattern
- add guardrail

4. Create Playbook Generator

Create playbook entries from learned strategy edge data.

Each playbook entry should include:

{
  playbook_entry_id,
  title,
  status: "ACTIVE" | "WATCHLIST" | "AVOID" | "REVIEW",
  symbol,
  timeframe,
  setupName,
  actionBias,
  conditionsRequired: [],
  entryRules: [],
  riskRules: [],
  invalidationRules: [],
  marketDataRequirements: [],
  sniperEntryRequirements: [],
  mistakeWarnings: [],
  confidenceLevel: "LOW" | "MEDIUM" | "HIGH",
  sampleSize,
  winRate,
  avgPnl,
  edgeScore,
  lastUpdated,
  source: "SYSTEM_GENERATED"
}

Rules:
- Do not mark anything HIGH confidence unless sample size is strong.
- Small sample size should be WATCHLIST, not ACTIVE.
- Losing setups should become REVIEW or AVOID.
- Repeated mistake patterns should become mistakeWarnings.
- Live trading must never be recommended.
