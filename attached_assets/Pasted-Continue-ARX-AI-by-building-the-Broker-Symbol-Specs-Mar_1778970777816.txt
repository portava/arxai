PART 4 — Broker Execution Rules Validator

Before any command queues, validate:

- symbol exists on routed MT5 account
- market is open if session data exists
- trade mode allows trading
- requested lot >= min lot
- requested lot <= max lot
- requested lot matches lot step
- SL/TP distance respects stops level
- price is valid for pending orders
- spread is not above user/admin limit
- margin estimate passes if margin data exists
- freeze level blocks unsafe modification if applicable
- account type matches demo/live mode
- command uses broker symbol, not only normalized symbol

If validation fails:
- reject before queue
- write risk_validation_logs
- show user-friendly reason
- do not send command to MT5
