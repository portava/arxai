Rules:
- Replay Lab cannot place trades.
- Replay Lab is simulation and learning only.
- Every replay must reconstruct:
  - candle sequence
  - market conditions
  - agent votes
  - judge verdict
  - execution conditions
  - Trader DNA state
  - cognitive state
  - global state
  - risk state
  - Control Tower mode
  - final outcome
- Replay must support branching alternate decision paths.
- Replay scoring must prioritize survival, consistency, drawdown control, discipline quality, expectancy, and execution realism — not only profit.
- Replay stress injection must simulate spread spikes, slippage, latency, fake breakouts, volatility shocks, and delayed execution.
- Replay clustering must group similar wins, losses, execution failures, overrides, and behavioral states.
- Lesson confidence must measure reliability before reinforcing learning.
- RegretRelief engine must track blocked losses avoided, blocked winners missed, stressful trades, confidence-damaging trades, and discipline-improving trades.
- Replay results can update Agent Performance, Trader DNA, Confidence Calibration, and Validation Readiness.
- All replay paths, simulations, lessons, and scoring outputs must be logged into the Black Box Vault.
- Keep all previous phase tests passing.
- No unrestricted live auto-execution yet.
