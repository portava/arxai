Build DD = Real Market Data Read Layer.

Goal:
Replace or supplement synthetic fallback data with a safe, read-only real market data layer that Build AA can use for better trade decisions.

Important:
Build DD must NOT place live trades.
Build DD must NOT modify live broker execution.
Build DD must NOT enable canPlaceTrades.
Build DD must NOT bypass Build AA, BB, or CC safety rules.
Build DD only gives the system better real-time market awareness.

Current system:
- Build AA = central trade decision orchestrator.
- Build BB = closed-trade auto-debrief.
- Build CC = learning feedback engine.
- Build DD must now provide reliable market data into Build AA.

Core requirement:
Create one unified market data adapter that can return real or fallback market data in one consistent format.

- marketDataService
