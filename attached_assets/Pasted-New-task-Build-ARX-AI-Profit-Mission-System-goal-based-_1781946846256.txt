New task: Build ARX AI Profit Mission System — goal-based trading missions, multi-agent trade selection, profit maximization, execution quality, and anti-blowup protection.

Goal:
Allow a user to give the AI a starting amount, a target amount, and a timeframe, then let the system build and manage a structured trading mission.

Example user prompts:
- “I have $1,000. Get it to $1,300 in 7 days.”
- “I have $500. Scalp aggressively today and try to make $75.”
- “Use this allocation and try to grow it to $5,000 by the end of the month.”
- “Trade gold only and try to reach this target by Friday.”

The system should convert the user’s request into a controlled AI Profit Mission.

Important:
Profit is the goal, but the bot must never force trades, gamble blindly, bypass risk controls, ignore feed truth, ignore broker truth, use martingale by default, or override live execution gates.

Core rule:
Maximize expected profit through edge quality, clean execution, smart sizing, active exits, profit protection, multi-agent learning, and refusing weak trades.

Do not promise guaranteed profit.
Do not use language like:
- guaranteed
- perfect
- risk-free
- can’t lose
- certain profit

Use:
- target
- mission
- probability
- feasibility
- expected return
- risk
- target pace
- progress
- confidence
- possible loss

SECTION 5 — Mission modes

Mission should automatically shift modes based on progress and risk.

Modes:
- Attack Mode
- Normal Mode
- Protect Mode
- Recovery Mode
- Cooldown Mode
- Stop Mode

Rules:
If ahead of pace:
- switch to Protect Mode
- reduce risk
- take fewer trades
- protect gains

If on pace:
- stay Normal Mode

If behind pace:
- switch to Attack Mode only if valid setups exist
- increase scanning, not reckless risk

If in drawdown:
- switch to Recovery Mode
- reduce lot size
- require higher quality setups

If consecutive losses:
- switch to Cooldown Mode
- pause trading for a set period

If mission loss limit hit:
- Stop Mode

Mission pressure cannot override risk protection.
