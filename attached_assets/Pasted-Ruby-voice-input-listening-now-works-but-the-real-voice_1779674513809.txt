BACKEND REQUIREMENTS
Create or repair a server-side Ruby TTS service with a clean provider abstraction:

RubyTTSService:
- speakWithOpenAI(text, options)
- speakWithElevenLabs(text, options)
- speakWithBrowserFallback(text, options)
- chooseProvider(userSettings/adminSettings/env)
- return playable audio to frontend

Add/repair backend route:
- POST /api/ruby/tts

Request body:
- text
- provider preference: auto/openai/elevenlabs/browser
- voice settings if allowed
- conversation id/message id if needed

Response:
Either:
- audio/mpeg or audio/wav binary audio
OR
- JSON with a secure temporary audio URL/blob reference

Do not return raw provider responses to frontend if they contain internal details.
