1. The frontend button/input exists.
2. The frontend action calls the correct backend route/service.
3. The backend validates the user and permission.
4. The backend calls the correct internal service or MT5 bridge action.

6. The database updates correctly if needed.

Dormant UI Cleanup:

For each dormant UI item:

1. Identify where it appears.
2. Check if it has a real function.
3. Check if it has backend wiring.
4. Check if it has database support.
5. Check if it has active user value.
6. If it is useful but disconnected, wire it properly.
7. If it is useful but too large/cluttered, collapse it into a menu, drawer, tooltip, or advanced section.
8. If it is truly dead, remove it.
9. If it is admin-only, hide it from normal users.
10. If it is repetitive, consolidate it into one clean status area.

Do not remove useful functionality just to reduce clutter.
Do not remove Scanner, Ruby, trade controls, admin controls, bridge controls, or risk controls.
Clean and simplify the UI without weakening the app.
