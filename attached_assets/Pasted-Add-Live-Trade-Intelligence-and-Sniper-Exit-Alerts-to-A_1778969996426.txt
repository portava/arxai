Goal:
Users should be able to ask the AI about any open demo/live trade and get intelligent trade management guidance.

The AI should answer questions like:
1. Where do you think this trade is going?
2. Why is the trade moving like this?
3. Should I keep holding?
4. When should I close?
5. Is this a pullback or retracement?
6. Is this continuation or a fakeout?
7. Is this a reversal?
8. Is price hunting liquidity?
9. Is my profit fading?
10. Should I close now, partial close, move stop loss, or wait?
11. What would invalidate this trade?
12. What is the best exit plan based on my timeframe?

Important safety behavior:
- AI must never guarantee profit.
- AI must never say it knows the future.
- AI must explain probabilities and scenarios.
- AI must clearly say when data is missing.
- AI must not silently close trades.
- Any close action must require user confirmation.
- Live close must require explicit confirmation.
- AI must not bypass backend trade guards.
- AI must not expose MT5 credentials, bridge tokens, API keys, secrets, or shared master account credentials.

Build this as a new system:

- lot size
- account type demo/live
- routing mode user-owned/shared-master
- open time

- profit giveback from peak
- position age
- current spread if available

- session context if available
- trend direction
- support/resistance zones if available
- liquidity zones if available
- news/economic risk if available
- user risk limits
- user trading style/timeframe if available

If some data is unavailable, do not fake it. Mark it as unavailable and continue with what exists.

SNIPER EXIT ALERTS

Add an alert system that monitors open trades and alerts users when the exit conditions become important.

Alert tiers:
1. Info
2. Watch
3. Warning
4. Urgent

Alert examples:
- “Your EURUSD buy is up 18 pips but profit has pulled back 35% from peak. Consider protecting profit.”
- “Momentum is weakening. This may be a retracement or early reversal.”
- “Price is approaching resistance. Watch for rejection.”
- “Close urgency is high. Tap to review close ticket.”
- “Your live trade is at risk of giving back profit. Review exit options.”

Alert rules:
- Alert when unrealized profit drops a configured percentage from peak.
- Alert when price approaches stop loss.
- Alert when price approaches take profit.
- Alert when reversalRiskScore rises above threshold.
- Alert when fakeoutRiskScore rises above threshold.
- Alert when closeUrgencyScore rises above threshold.
- Alert before high-impact news if economic calendar data exists.
- Alert when spread/volatility becomes dangerous if available.
- Alert when trade exceeds user’s intended hold time.
- Alert when trade reaches user-defined profit target.
- Alert when trade moves from profit to near break-even.

Add user preferences:
- enable/disable trade intelligence alerts
- alert threshold conservative/balanced/aggressive
- preferred trade style:
  - scalping
  - intraday
  - swing
  - custom
- preferred check frequency
- profit giveback alert percentage
- minimum P&L before close alerts
- allow push notifications
- allow in-app alerts
- allow sound/vibration if supported

SNIPER CLOSE FLOW

When the AI thinks the user should consider closing:
1. Send alert.
2. Show trade card with reason.
3. Show “Review Close” button.
4. Open close confirmation modal.
5. Modal shows:
   - symbol
   - side
   - lot size
   - current P&L
   - peak P&L
   - profit giveback
   - reason for close alert
   - account type demo/live
   - routing mode
   - warning if live
6. User confirms.
7. Backend validates full close guard chain again.
8. Queue CLOSE_POSITION command.
9. Audit log records the full lifecycle.
10. UI shows Closing / Closed / Rejected.

For live trades:
- Never instant-close from alert.
- Require explicit confirmation.
- Modal must say:
  “This will close a LIVE trade and may realize profit or loss.”
- Keep confirmedByUser:true requirement.

Update AI context so the user can ask about a specific open trade.

The AI should support:

- “Should I close my gold trade?”
- “Is this a fakeout?”
- “Is this just a pullback?”
- “Why is my trade negative?”

- “Where is price likely heading next?”
- “What is the safest close plan?”
- “What should I watch for in the next 5 minutes?”
- “Set an alert if this starts reversing.”
- “Tell me when I should consider closing.”

AI response format should include:
1. Current trade status
2. What price is doing
3. Scenario A: continuation
4. Scenario B: pullback/retracement
5. Scenario C: reversal/fakeout
6. Key level to watch
7. Exit plan
8. Risk warning
9. Suggested action button if applicable:
   - Review Close
   - Set Alert
   - Hold and Monitor
   - Partial Close Review
   - Move Stop Review

Example response:
“Your EURUSD buy is currently +12.4 pips. Momentum is still holding, but profit has pulled back 28% from the peak. This looks more like a healthy pullback unless price breaks below 1.08420. If it rejects again at resistance, close urgency increases. Suggested action: hold for now, but set a close alert below 1.08420.”

Do not use fake market data. If candles or scanner data are missing, say:
“I can see your MT5 position and P&L, but I do not have enough live candle/scanner data to judge continuation vs fakeout accurately.”
