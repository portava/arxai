Build ARX Fund Book Phase 1: investor ledger, strategy pool NAV, unit accounting, live broker mirror overlay, real-time investor P/L, drawdown, withdrawal/deposit fee logic, and discrepancy controls.

This is the foundation for managing investor funds while using a shared live broker bridge.

This is NOT a trading execution change.
Do not change the live bridge execution path.
Do not place any live trade for this build.
Do not add Paper Trading, simulator, mock, fake, sandbox, or test-trading language.
Do not expose backend table names, route names, raw JSON, stack traces, or developer wording to investors.

Main principle:
The broker account is shared.
Investor accounting is separate.
Every investor must only see their own ledger, units, allocation, P/L, drawdown, fees, withdrawals, deposits, and statements.

Investor balances must start from the investor’s own approved ledger balance, not from the master broker balance.

The broker mirror is only used to apply that investor’s verified proportional share of live pool P/L, drawdown, and exposure.

No bleed-over.
No cross-investor visibility.
No guessing.
No direct splitting of the full broker balance unless investor units prove the exact share.

PART 2 — CORE ARCHITECTURE
====================================================

Create/upgrade the ARX Fund Book architecture:

1. Broker Mirror Layer
Mirrors real broker account state exactly as received from the bridge.

2. Master Fund Book
Tracks total internal fund accounting across all investors and pools.

3. Strategy Pool Ledger
Tracks Conservative, Balanced, Aggressive, and Cash Reserve pools.

4. Unit-Based NAV Engine
Calculates pool NAV and investor unit value.

5. Investor Ledger
Tracks each investor’s deposits, withdrawals, fees, P/L, adjustments, and current value.

6. Investor Pool Holdings
Tracks how many units each investor owns in each pool.

7. Trade-to-Pool Allocation
Maps live broker positions/trades to strategy pools.

8. Real-Time P/L Allocator
Applies pool P/L to investor values based on units.

9. Drawdown Engine
Tracks master, pool, investor, and trade drawdown.

10. Discrepancy/Reconciliation Center
Compares broker mirror, pool NAV, investor ledger, and displayed values.

11. Capital Movement System
Handles deposit requests, withdrawal requests, speed-based fees, settlement status, and admin approvals.

12. Audit + Statement System
Tracks every financial change and produces transparent investor records.

====================================================
PART 5 — UNIT-BASED NAV ACCOUNTING
====================================================

Implement unit-based NAV accounting.

Core rule:
Units are not fixed-limited supply.
Units are variable-supply internal accounting shares.

Units are only created when:
- deposit is approved/settled
- allocation is approved
- NAV is confirmed
- audit log is created

Units are redeemed when:
- withdrawal is approved
- pool redemption is processed
- NAV is confirmed
- audit log is created

Pool NAV formula:

Pool NAV = Pool Net Value / Total Pool Units

Pool Net Value =
Starting Pool Capital
+ Realized P/L
+ Unrealized P/L
+ Deposits allocated to the pool
- Withdrawals redeemed from the pool
- Fees
+/- Approved Adjustments

Investor Pool Value =
Investor Pool Units × Current Pool NAV

Investor Ownership % =
Investor Pool Units / Total Pool Units

Investor Gain Share =
Pool Gain × Investor Ownership %

Investor Unrealized P/L =
Pool Open P/L × Investor Ownership %

Investor Total Value =
Cash Reserve
+ Conservative Units × Conservative NAV
+ Balanced Units × Balanced NAV
+ Aggressive Units × Aggressive NAV
- Fees
+/- Approved Adjustments

Important:
Deposits increase pool value and total units.
Deposits must not artificially increase NAV.

Withdrawals reduce pool value and redeem units.
Withdrawals must not artificially decrease NAV.

Trading performance changes NAV.
Fees and approved adjustments affect net investor value.

====================================================
PART 6 — STARTING NAV AND UNIT ISSUANCE
====================================================

Each strategy pool starts at:

Starting NAV = $1.00 per unit

Example:
Investor deposits $10,000 into Balanced when NAV is $1.00.
Investor receives 10,000 Balanced units.

If later Balanced NAV is $1.25 and a new investor deposits $10,000:
New investor receives 8,000 units.

Formula:
New Units Issued = Net Deposit Allocated to Pool / Current Pool NAV

Withdrawal formula:
Units Redeemed = Gross Withdrawal From Pool / Current Pool NAV

Investor value:
Investor Pool Value = Investor Units × Current Pool NAV

Do not create arbitrary units.
Do not issue units without approved ledger entry.
Do not redeem units without approved withdrawal/capital movement entry.
Every unit issuance/redemption must be auditable.
