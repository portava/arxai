- GET /api/me/paper-trades
- POST /api/me/paper-trades

- PATCH /api/me/paper-trades/:id

- POST /api/me/paper-trades/:id/close
- POST /api/me/paper-trades/:id/cancel
- GET /api/me/trading-sessions/:id/paper-trades

Requirements:
- requireUser on every route.
- userId = req.authUser.id on every query.
- Validate symbol, side, size, entry, stop loss, take profit.
- Block impossible values such as negative lot size, invalid price, missing symbol.
- Calculate risk/reward safely when enough values exist.
- Calculate P/L when closed.
- Closing a trade should update the connected trading session metrics.
