==================================================
CORE PRODUCT RULE
==================================================

Once funds are allocated to a Self-Trade AI agent and the agent is active, that agent is allowed to autonomously scan, decide, enter, manage, exit, review, and learn from trades without user input.

No user confirmation should be required after allocation and activation, unless:
- admin settings require confirmation
- agent autonomy level is below full autonomous
- Risk Governor blocks the trade
- bridge/account/feed is unavailable
- daily/weekly loss limit is hit
- global or agent kill switch is active
- agent is paused
- the trade violates assigned rules

Core logic:

No funds = no autonomous trading.
Funds allocated + agent active + autonomy level allows execution + all handshakes pass = autonomous trading allowed.
Any failed hard safety handshake = no trade.

AGENT AUTONOMY LEVELS
==================================================

Support autonomy levels:

Level 0: Shadow only
- Watches and logs hypothetical decisions.
- No live orders.

Level 1: Prepare trades only
- Creates trade ideas/tickets.
- No autonomous execution.

Level 2: Execute entries, manual exits
- Can enter trades.
- Cannot manage/exit unless manually approved or existing rules allow.

Level 3: Execute and manage positions

Level 4: Full autonomous lifecycle
- Can scan, enter, manage, exit, review, and learn within allocation/risk rules.

Autonomy level must be admin-controlled.

==================================================
MANDATORY DAILY TRADE RULE
==================================================

Funded active self-trade agents must complete at least 3 trades per trading day.

Rule:

Daily Minimum Trades: 3
Base Daily Max Trades: 5
Extension allowed after 5 only if healthy.

The daily minimum counts only:
- real executed trades
- MT5-confirmed entries
- agent-owned trades
- trades tied to that agent’s allocation

Do not count:
- rejected orders
- cancelled setups
- watch-only alerts
- manual user trades
- duplicate partial fills unless system intentionally counts them as separate trades
- scanner ideas that were not executed

The agent must continuously scan approved symbols until the minimum is completed unless a hard block prevents it.

Allowed reasons to miss the 3-trade minimum:
- no funds allocated
- agent paused
- admin disabled agent
- global kill switch active
- agent kill switch active
- bridge unavailable
- price/feed unavailable
- daily loss limit hit
- weekly loss limit hit
- risk governor hard block
- no approved symbols available
- account allocation insufficient

Anything else must be logged as missed quota.

==================================================
TRADE QUOTA ESCALATION
==================================================

Agents must satisfy the 3-trade minimum intelligently, not recklessly.

Daily trade quota logic:

0–40% of trading day passed:
- highest-quality setups only
- minimum setup score 80+
- normal risk allowed if all checks pass

40–70% of trading day passed:
- broaden scanner universe
- allow scalp and swing if agent supports both
- minimum setup score 75+
- normal or slightly reduced risk

70–90% of trading day passed:
- quota completion mode
- minimum setup score 70+
- reduced lot size required
- extra confirmation required
- no correlated stacking
- no dangerous news unless News Agent authorized

90%+ of trading day passed:
- minimum safe setup allowed only
- reduced risk
- no add-ons
- if no acceptable setup, log hard/soft reason

Quota pressure field:
Low / Medium / High / Critical

If quota pressure is high:
- reduce position size
- require additional confirmation
- increase audit logging
- alert My Alerts / Live Decisions
- mark trade as quota-driven

Self-trade must reduce or stop action if data is unreliable:

- price feed stale
- candles missing
- economic calendar unavailable
- spread feed unavailable
- MT5 heartbeat stale
- open positions not refreshing
- balance mismatch
- duplicate symbol mapping
- selected symbol mismatch
- account allocation mismatch

Alert:
Self-trade paused: position data is stale.
Reason: MT5 heartbeat has not updated.

==================================================
RECOVERY MODE
==================================================

If agent is down but not stopped:

Recovery Mode:
- smaller lot size
- no extension trades
- higher minimum setup score
- no news trades
- no add-ons
- one open trade at a time

==================================================
PROFIT LOCK / PROTECT MODE
==================================================

If agent hits daily/weekly goal:

Protect Mode:
- only A+ setups
- reduced risk
- no quota pressure if minimum completed
- optional stop-for-day setting
- protect existing positions

==================================================
AGENT PROMOTION / DEMOTION
==================================================

Agents should be promoted/demoted based on:
- P/L
- P/L percentage on allocation
- drawdown
- profit factor
- win rate
- risk discipline
- quota completion
- execution quality
- news handling
- consistency
- confidence calibration
- slippage control

Examples:
- promote: increase risk slightly, allow extension, expand symbols
- demote: reduce risk, disable news, raise score threshold, move to shadow mode

Major promotions/demotions require admin approval if they alter risk materially.

==================================================
AGENT RETIREMENT
==================================================

Rules:
- loses 3 weeks in row → move to Shadow Mode
- drawdown exceeds max → freeze allocation
- rule discipline below 60 → disable autonomous trading
- repeated news losses → disable news trading

==================================================
SHADOW MODE
==================================================

Shadow Mode is not user paper trading. It is internal live-market evaluation.

Agent logs:
- would-have-entered trade
- SL/TP
- expected result
- actual result
- why it did/did not trade

Eligibility for live allocation:
- shadow score above threshold for X days
- max drawdown below threshold
- minimum shadow trades
- rule discipline threshold
- news safety score

- own closed trades

- news outcomes

- rejected setups
- trade management outcomes

Learning outputs:
- market specialization
- strategy specialization
- session preferences

- market bans
- promotion/demotion recommendations

Agents may learn from each other only through validated patterns, not blind copying.

- calibration gap

- not late

- thesis followed
