PART D — Fix slow categories

Fix each category based on evidence.

1. If T1 visual feedback is slow:
- move expensive work out of click handler
- set local pressed/loading state immediately
- defer heavy work with requestAnimationFrame/setTimeout 0 where safe
- split component
- reduce synchronous calculations

2. If modal opening is slow:
- lazy-load heavy internals after modal shell appears
- render modal shell first
- defer chart/history/Ruby sections
- remove duplicate hidden modals
- prefetch only lightweight profile data

3. If API start is slow:
- remove synchronous preflight work before fetch
- use cached account-mode/profile
- avoid waiting for unrelated queries before request

4. If backend is slow:
- consolidate DB queries
- add indexes
- avoid N+1
- cache static config
- cache symbol maps
- cache owner profile
- remove heavy diagnostics from normal route

5. If provider is slow:
- separate provider latency from UI feedback
- show immediate “checking broker/feed” state
- use recent cached quote/candle
- do not block entire UI
- time out cleanly with retry

6. If render is slow:
- memoize expensive components
- virtualize lists
- split pages
- lazy-load hidden tabs
- avoid rerendering all cards on one tick
- stabilize props/callbacks

7. If duplicate requests:
- fix query keys
- set staleTime
- use enabled flags
- use shared hooks
- remove duplicate useEffect fetches
- cancel stale queries

8. If polling/subscriptions cause lag:
- centralize interval ownership
- pause hidden pages
- reduce intervals
- dedupe subscriptions
- cleanup on unmount
- avoid whole-app rerender per tick
