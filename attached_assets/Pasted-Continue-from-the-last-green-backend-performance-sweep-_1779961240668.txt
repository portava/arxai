Part 3 — Fix What Fails

If any UI timing test fails:
1. Identify exact component/file.
2. Fix the slow path.
3. Prefer memoization, lazy loading, smaller payloads, debounced inputs, proper suspense/loading states, and reduced duplicate requests.
4. Remove dead UI branches.
5. Avoid adding global polling.
6. Avoid blocking page render on non-critical data.
7. Avoid making backend calls before the page actually needs them.
8. Retest the failed action.
9. Then rerun the whole sweep.
