- Live trading is still disabled.
- Secrets are protected.
- Security permissions work.
- Read-only broker mode is enforced.
- Notifications fire correctly.

6. Readiness scoring

Score 0–100.

Suggested categories:
- Safety and live-trade lock: 25 points
- Security/data protection: 20 points
- Core paper workflow AA-CC-EE: 20 points
- Market data/replay/import reliability DD-JJ-KK: 10 points
- Performance/coach/notifications/admin GG-II-LL-MM: 15 points
- Frontend/accessibility/smoke checks: 10 points

Hard fail conditions:
- live trading enabled
- canPlaceTrades true
- broker mode not read_only
- market data mode not read_only
- forbidden admin action succeeds
- secrets exposed
- paper execution calls live broker code
- critical security middleware missing
- readiness gate cannot run

If any hard fail occurs:
overallStatus must be "BLOCKED" or "FAIL"
canProceedToPaperTesting can be false
canProceedToLiveTrading must always be false
