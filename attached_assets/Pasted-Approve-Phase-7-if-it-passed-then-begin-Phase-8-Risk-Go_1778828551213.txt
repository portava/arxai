Phase 8C — Risk check engine:
Create a central risk governor service used before opening any paper trade or queuing any trading-related command.

The risk engine should evaluate:
1. Does the user have risk settings?
2. Is liveLocked still true?
3. Is allowOrderExecution still false?
4. Is the app in paper/read-only mode?
5. Is stop loss required and present?
6. Is take profit required and present?
7. Is risk per trade within user limits?
8. Is reward-to-risk above minimum?
9. Is the user under max trades per day?
10. Is the user under max open trades?
11. Has the user hit max daily loss?
12. Has the user hit max weekly loss?
13. Has the user hit max consecutive losses?
14. Is the user in cooldown?
15. Is this trade tied to a playbook if required?
16. Did the pre-trade checklist pass if required?
17. Did the user write a reason for entry if required?
18. Does recent behavior suggest revenge trading?
19. Does recent behavior suggest overtrading?
20. Is anything attempting live execution?

Output:
- decision: pass / warning / block
- riskScore 0–100
- failedRules
- warnings
- requiredActions
- overrideAllowed boolean
- reason
- details

Hard rule:
Any live execution intent must be blocked regardless of override.

Phase 8E — Integrate with paper trade lifecycle:
Before a paper trade can be opened:
1. Run pre-trade checklist from Phase 7 if required.
2. Run Risk Governor.
3. If decision = pass, allow paper trade open.
4. If decision = warning, allow paper trade open only with warning acknowledgement.
5. If decision = block, block paper trade unless paper override is allowed and user provides reason.
6. Log every risk decision to risk_governor_events.

When a paper trade closes:
- update session metrics
- update calendar
- check daily loss
- check consecutive losses
- trigger cooldown if rules require it
- log risk events if limits are hit

Phase 8F — Integrate with MT5 command routing:
Before any command is queued:
- Run safety classification.
- Allow only safe paper/read-only commands.
- Block anything live or broker-mutating.

Allowed:
- PING
- HEARTBEAT_TEST
- ACCOUNT_SNAPSHOT_REQUEST
- POSITIONS_SNAPSHOT_REQUEST
- PAPER_ORDER_TEST if app-only simulation

Blocked:
- LIVE_BUY
- LIVE_SELL
- MODIFY_LIVE_ORDER
- CLOSE_LIVE_POSITION
- any command that could call OrderSend
- any command that could mutate a real broker position

Log blocked attempts as:
eventType = live_execution_blocked
severity = critical
decision = block
