2. EA must send token securely

Every request from MT5 EA to Replit must include:

X-MT5-Bridge-Token: <token>

Do not expose token in logs.
Do not hardcode token into source.
User will paste token into EA input settings manually.

GET /api/broker/connection-check
GET /api/broker/status
GET /api/broker/account
GET /api/positions/live
GET /api/orders/live

4. Read-only first

The first EA version must be READ-ONLY.

It may:
- send heartbeat
- send account balance/equity/margin
- send open positions
- send open orders
- send symbol/spread info
- poll for commands

It must NOT:
- place live orders
- close live positions
- modify live orders
- cancel live orders
- call OrderSend
- call trade execution methods

If a command attempts execution while ReadOnlyMode=true, the EA must reject it and report:

"EA_READ_ONLY_MODE_ACTIVE"
