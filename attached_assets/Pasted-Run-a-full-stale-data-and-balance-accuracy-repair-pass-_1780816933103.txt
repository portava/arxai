PHASE 2 — DEFINE SOURCE OF TRUTH

Establish clear source-of-truth rules.

For live trading account values:
- Source should be the live MT5/Deriv bridge account snapshot when available.
- Balance, equity, margin, free margin, margin level, open P/L, and account currency should come from broker/bridge snapshot.
- If bridge data is unavailable, show “Waiting for live account update” or “Account data unavailable” instead of fake numbers.
- Never show dummy fallback balances as real values.

For user allocation values:
- Source should be the app’s user allocation ledger/database.
- Allocation balance must reconcile to admin-assigned allocation and any approved capital movements.
- Do not invent user balances from the master balance.
- If allocation is not configured, show “No allocation assigned yet” instead of $0 if $0 would be misleading.

For investor/view-only values:
- Source should be investor ledger/reporting data only.
- Investors must not see trader controls or broker execution balances unless intentionally summarized as investor-safe reporting.
- If investor reporting data is not yet available, show an honest empty state, not dummy values.

For admin/OWNER:
- Admin can see master account, bridge snapshot, user allocations, investor records, and reconciliation state where role-appropriate.
- Admin screens should clearly distinguish broker balance, app allocation, investor capital, realized P/L, unrealized P/L, and pending capital movements.
