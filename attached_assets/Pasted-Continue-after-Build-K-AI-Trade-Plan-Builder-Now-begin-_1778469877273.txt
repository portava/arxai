- WEEKLY_REVIEW
- REPLAY_DRILL
- EXECUTION_SAFETY

4. Priority levels:
- LOW
- MEDIUM
- HIGH
- CRITICAL

5. Add alert rules:
- Alert when market changes to NO TRADE
- Alert when broker disconnects
- Alert when price feed is delayed
- Alert when position approaches stop loss
- Alert when trade plan becomes invalid
- Alert when risk lock activates
- Alert when weekly review is ready
- Alert when AI recommends a replay drill
- Alert when user is nearing daily loss limit

6. API routes:
- GET alerts
- GET unread alert count
- PATCH mark alert as read
- PATCH mark all alerts as read
- GET alert preferences
- PATCH update alert preferences
- POST generate system alert

7. Frontend components:
- Notification Bell

- Show unread count
- Allow user to click alert and go to related page

- Do not create duplicate alerts for the same event.
- Critical safety alerts should be highly visible.
- No alert should claim guaranteed profit.
