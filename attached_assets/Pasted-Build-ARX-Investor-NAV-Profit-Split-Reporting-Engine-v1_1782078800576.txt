Build ARX Investor NAV + Profit Split + Reporting Engine v1.

Goal:
Create the internal accounting engine that calculates investor value, pool NAV, profit/loss, lockups, ARX profit share, and investor statements after deposits are confirmed and allocated.

This should connect to:
- InvestorAccount
- InvestorDeposit
- CryptoFundingIntent
- CryptoFundingTransaction
- TreasuryWallet
- InvestorAllocation
- InvestorLedgerEntry
- InvestorWithdrawalRequest
- InvestorPool
- BrokerTransferIntent

Important:
Do not let investors trade.
Do not let investors move funds.
Do not use guaranteed-return language.
Do not count pending/unconfirmed deposits.
Do not count broker transfer intents as investor profit/loss.
Do not mix pool accounting with live trade execution gates.

Core concept:
Investor value should be based on pool NAV and investor units.

Formula:
- units = principalAmount / navPerUnitAtEntry
- currentValue = activeUnits * currentNavPerUnit
- grossPnL = currentValue - principalAmount
- profitSplit applies only to realized profit, not principal

Example:
Investor deposits $1,000.
Pool NAV at entry = $100.
Investor receives 10 units.
Later NAV = $120.
Investor current value = 10 * $120 = $1,200.
Gross profit = $200.

If profit split is 60/40 investor/ARX:
Investor keeps $120 profit.
ARX earns $80 performance share.
Investor net value = $1,120.

2. Profit Split Engine

Add service:
server/investors/profitSplitEngine.ts

Pool settings:
- investorProfitSharePct
- arxProfitSharePct
- performanceFeeMode
  - realized_only
  - snapshot_based
  - disabled
- highWaterMarkEnabled
- crystallizationFrequency
  - weekly
  - monthly
  - withdrawal_only

Default for v1:
- investorProfitSharePct = 60
- arxProfitSharePct = 40
- performanceFeeMode = realized_only
- highWaterMarkEnabled = true
- crystallizationFrequency = withdrawal_only

Rules:
- ARX performance share applies only to profits.
- Never take ARX share from principal.
- If investor is in loss, ARX share is 0.
- Use high-water mark so ARX does not charge again on already-counted profit.
- Store profit split calculations in ledger entries.
- Investor dashboard must show gross P/L and net value clearly.

3. High-Water Mark

Add high-water mark tracking per allocation.

InvestorAllocation add fields:
- highWaterMarkValue
- totalArxPerformanceShareCharged
- totalInvestorProfitCredited
- lastProfitSplitAt

Rule:
If current value is below or equal to highWaterMarkValue:
- no new ARX performance share
- investor value updates with gross P/L
- no performance share charged

If current value is above highWaterMarkValue:
- charge ARX share only on new profit above high-water mark

Example:
Principal: $1,000
High-water mark: $1,100
Current value: $1,300
New chargeable profit: $200
If 60/40:
- investor new profit share: $120
- ARX new share: $80
