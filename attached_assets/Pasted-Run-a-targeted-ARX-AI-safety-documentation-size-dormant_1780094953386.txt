Part 5 — Safe cleanup rules

Only remove or archive code when all of these are true:

1. It is not imported anywhere.
2. It is not dynamically routed.
3. It is not referenced by config.
4. It is not referenced by tests.
5. It is not needed by deployment/build.
6. It is not a database migration/schema file.
7. It is not a bridge/auth/security file.
8. It is not used by Ruby action registry.
9. It is not used by Scanner, trade execution, admin controls, or user account mode.

If unsure:

3. Leave a note in the audit report.
