Phase 2 — Polish the final animation
Make the animation feel premium but lightweight.

Refine:
- idle AI-core glow
- open chat-bubble state

- closing transition from chat bubble back to AI orb
- thinking/loading particle orbit
- answer-ready pulse
- warning/blocker amber ring
- error red ring

- tap feedback on mobile

Keep it smooth:
- no layout shift
- no page reflow
- no large assets
- no GIF/video
- no heavy new animation dependency

Use SVG/CSS unless an existing animation library is already installed.

Phase 3 — Add design tokens
Create clean styling variables for the icon.

Suggested tokens:
- assistant icon size mobile
- assistant icon size desktop
- cyan glow color
- dark glass background
- amber warning ring
- red error ring
- shadow/glow intensity
- z-index

- desktop bottom/right offset
