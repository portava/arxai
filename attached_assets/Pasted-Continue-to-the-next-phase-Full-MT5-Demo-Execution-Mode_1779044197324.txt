- PAPER
- MT5_DEMO_READ_ONLY
- MT5_DEMO_EXECUTION
- LIVE_LOCKED

Rules:
- Default must remain PAPER or MT5_DEMO_READ_ONLY.
- User must explicitly opt into MT5_DEMO_EXECUTION.
- LIVE_LOCKED must remain locked.
- Demo execution must never share logic with live unlock.
- Demo execution must require connected MT5 bridge + fresh heartbeat + verified demo account.

Before any MT5 command can execute, verify:
- bridgeConnected=true
- eaConnected=true
- heartbeatFresh=true
- readOnlyMode can become false only for demo mode
- allowOrderExecution=true only for demo mode
- commandExecutionAllowed=true only for demo mode
- broker account is demo
- account login matches the user’s connected MT5 account
- user owns the bridge connection
- per-user bridge token is valid
- no duplicate EA/token warnings
- broker snapshot fresh enough
- market data available when required
- risk limits pass
- prop firm guardrails pass if enabled
- user confirmation was given

If any check fails:
- command status = BLOCKED or REJECTED
- show clear reason
- audit it
- do not send to MT5
