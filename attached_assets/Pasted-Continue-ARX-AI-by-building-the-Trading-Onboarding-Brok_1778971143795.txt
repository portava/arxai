Continue ARX AI by building the Trading Onboarding, Broker Connection, and User Readiness Wizard.

Do not rebuild blindly. Inspect the current:
- login/auth system
- user profile/settings
- admin trading controls
- platform trading mode: Trading Off / Demo / Live
- account routing mode: USER_OWNED_MT5 / SHARED_MASTER_MT5
- MT5 bridge connection flow
- per-user bridge tokens
- shared master account routing
- user risk profiles
- alert preferences
- strategy playbooks
- Risk Governor
- Broker Symbol Specs Engine
- Trade Action Center
- AI assistant context builder
- notification system
- mobile layout

Goal:
Create a guided onboarding system so every user can safely set up their account before trading.

Important:
Do not expose MT5 credentials, bridge tokens, API keys, session secrets, shared master credentials, or any private admin secrets.
Do not enable live trading automatically.
Do not bypass admin approval.
Do not let users trade until required setup steps are complete.
Live trading still requires approval, disclosure, verified live account, and explicit confirmation.

PART 1 — User Trading Readiness Wizard

Create a step-by-step onboarding flow:

Step 1 — Welcome
- Explain ARX AI trading modes:
  - Trading Off
  - Demo Trading
  - Live Trading
- Explain routing modes:
  - Your connected MT5 account
  - Shared master account if admin enables it
- Explain that AI gives decision support, not guaranteed outcomes.

Step 2 — Risk Profile
User selects:
- Conservative
- Balanced
- Aggressive
- Custom

Collect:
- max daily loss
- risk per trade
- max trades per day
- max open trades
- preferred symbols
- preferred trading style:
  - scalping
  - intraday
  - swing
  - custom

Step 3 — Account Routing
Show the routing mode available to this user:
- User-owned MT5
- Shared master MT5
- Admin-selected/inherited mode

If USER_OWNED_MT5:
- guide user to connect their MT5 account
- show demo/live account type after sync

If SHARED_MASTER_MT5:
- show user virtual account/allocation status
- do not show master credentials
- explain that trades are tracked by ARX AI allocation ledger

Step 4 — MT5 Connection
For user-owned MT5:
- show bridge connection instructions
- show backend base URL
- show token setup instructions safely
- do not reveal raw token after initial secure generation
- show heartbeat status
- show sync-account status
- show sync-positions status
- show command polling status
- show account type demo/live

Step 5 — Alerts
User configures:
- trade exit alerts
- push alerts if available
- in-app alerts
- profit giveback alerts
- news/event risk alerts
- MT5 disconnect alerts
- broker rejection alerts
- quiet hours
- alert sensitivity

Step 6 — Strategy Setup
User can:
- choose a default strategy template
- create first playbook
- skip and use “manual trading”
- set preferred symbols/timeframes/sessions

Step 7 — Live Trading Disclosure
Only show when user is live eligible or requesting live.
Require:
- live risk disclosure acceptance
- acknowledgement that live trades can lose real money
- confirmation that user understands AI is not guaranteed
- timestamp acceptance
- store acceptance record

Step 8 — Readiness Check
Show final checklist:
- profile complete
- risk profile set
- routing mode resolved
- MT5 connected or shared allocation active
- account type detected
- alerts configured
- strategy/playbook selected or skipped
- live disclosure accepted if live
- admin approval status
- Risk Governor status
- trading mode status

Output:
- Ready for Demo
- Ready for Live Pending Admin Approval
- Ready for Live
- Not Ready, with blockers
