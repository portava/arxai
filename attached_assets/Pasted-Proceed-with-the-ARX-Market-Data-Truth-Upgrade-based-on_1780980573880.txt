Proceed with the ARX Market Data Truth Upgrade based on the completed Market-Data / API Inventory Audit.

The audit found that the execution boundary is safe: live execution, fills, positions, balance, equity, margin, open trades, and allocation are broker-truth only through the MT5 bridge and arx_live_* tables.

Do not change live execution routing.
Do not create a new execution path.
Do not let external feeds affect fills, balance, equity, or broker execution price.
Do not weaken the 16-gate live command pipeline.
Do not bypass Risk Governor, AACI, or Security Handshake.

The problem is analysis/chart truth:
- MT5 broker quote/candle slot exists but is inactive.
- EA currently heartbeats but does not push real candles/quotes.
- Forex charts can fall through to TwelveData/Polygon.
- Polygon free-tier intraday can be delayed/stale.
- Scanner still has simulator fallback for technicals.
- Legacy /api/data/candles still exists as a bare endpoint.
- Stale/freshness thresholds live in multiple places.
- Ruby and scanner must stay honest when feed is delayed or not AI-usable.

==================================================
PRIMARY GOAL
==================================================

Make ARX market-data truth stronger and cleaner without disturbing the safe broker execution boundary.

Target architecture:

Execution/account truth:
MT5 bridge only → arx_live_commands / arx_live_positions / mt5_connection

Analysis/chart truth:
mt5_broker candles/quotes first → Deriv for synthetics → assistant_real fallback only when clearly labeled

No simulator or delayed fallback should look like live broker truth.
