On the Cockpit / Shared Master Account card, the balance/equity/open positions are not updating in real time and the refresh button does not appear to actually refresh the live MT5 account state.

User screenshot shows:

* Shared Master Account
* LIVE
* Virtual Balance: $7.00
* Equity: $7.00
* Open PNL: $0.00
* Realized (7D): $0.00
* Broker: Deriv (SVG) LLC ••••0041 LIVE

* Refresh icon is visible but the user says it is not refreshable

Required behavior:
ARX must actively sync with MT5 balance/equity/open positions/P&L in near real time, whether a trade is placed:

1. through ARX, or
2. directly inside MT5.

This task is only for live account sync/refresh.
Do not change governance.
Do not change live trade restrictions.
Do not change order execution.
Do not use Demo.

PART 3 — Fix the refresh button

The refresh button on the Shared Master Account card must trigger a real sync.

When owner/admin taps refresh:

1. call backend refresh endpoint
2. backend requests latest MT5 account snapshot from bridge/EA
3. backend requests latest MT5 open positions from bridge/EA
4. backend reconciles ARX open positions against MT5 open positions
5. backend updates account snapshot cache
6. frontend refetches and displays updated values
7. UI shows loading state during refresh
8. UI shows last updated timestamp after refresh
9. UI shows clean failure if bridge/EA unavailable

Do not let refresh only refetch stale database values.
Do not fake refresh by updating timestamp only.

PART 4 — Add near-real-time sync

Implement near-real-time live sync for the owner/admin Shared Master Account.

Requirements:

1. Poll or subscribe to MT5 account snapshot on a safe interval.
2. Suggested interval: every 2–5 seconds while Cockpit/Trade/Scanner is visible.
3. Pause or slow polling when tab is hidden.
4. Do not create excessive backend load.
5. Do not block page render on sync.
6. Show stale indicator if last MT5 sync is old.
7. If bridge heartbeat is healthy but account snapshot is stale, show warning.
8. If bridge disconnected, show clean “MT5 sync unavailable.”

The sync should include:

1. balance
2. equity
3. margin
4. free margin
5. open P/L
6. open position count
7. account currency
8. broker/server/account label if safe
9. timestamp from MT5 or bridge receipt time

PART 5 — Direct MT5 trades must reflect in ARX

ARX must update if a trade is placed manually in MT5.

Required:

1. If a user opens a trade directly inside MT5, ARX detects the new MT5 open position on next sync.
2. If the trade belongs to the shared master account, it appears in admin/owner shared master view.
3. If ARX cannot attribute the manual MT5 trade to a specific ARX user, mark it as:
    * Source: Manual MT5
    * Attribution: Unassigned / Admin review
4. Do not assign manual MT5 trades to a random user.
5. Do not expose manual MT5 trades to normal users unless attributed/authorized.
6. Admin/owner should see unattributed manual MT5 trades in a clear section.
7. If the manual MT5 trade closes, ARX detects and marks it closed/reconciled.
