Update ARX Pattern Sync System: Admin Cockpit Only + Full Trader/Investor Account Visibility

Scope change:
Pattern Sync must be built as an ADMIN COCKPIT feature only unless explicitly enabled later. Do not expose Pattern Sync to normal traders or investors by default.

The Admin Cockpit should become a true control-room/cockpit view: informative, dense, real-time, and operational. It should let the admin see the full live condition of the platform, each trader account, each investor account, bridge status, trade activity, Pattern Sync intelligence, risk state, balances, allocations, open positions, and warning signals from one place.

Feature name:
Admin Cockpit

Primary sections:
1. Cockpit Overview
2. Trader Accounts
3. Investor Accounts
4. Live Bridge / MT5 Status
5. Pattern Sync Command Center
6. Open Trades / Exposure
7. Risk & Alerts
8. Capital / Pool / Allocation
9. Approval & Activation Controls
10. Audit Log / Timeline

5. Pattern Sync Command Center

Pattern Sync belongs inside Admin Cockpit only.

Admin should see:
- market leader symbol
- follower symbols
- lagging symbols
- same-pattern scores
- H4 bias
- M15 timing
- fakeout risk
- clean setup score
- choppy setup score
- continuation score
- pullback score
- symbols with late-entry risk
- symbols with countertrend open trades
- symbols near key support/resistance

Default comparison symbols:
- V25(1s)
- V50
- V50(1s)
- V75
- V75(1s)

Pattern Sync table columns:
- symbol
- timeframe
- pattern type
- leader/follower/lagging status
- match score
- trend bias
- H4/M15 alignment
- clean setup score
- fakeout risk
- key support
- key resistance
- admin summary

Example cockpit summary:
“V75 is the current market leader. V25(1s) is following the same bullish recovery pattern but has pulled back deeper. V50 is similar but still choppy and not confirmed. V50(1s) has a countertrend sell risk after a strong bullish rally.”

Pattern Sync should help admin understand the market, trader exposure, and risk. It should not auto-execute trades or bypass safety.
