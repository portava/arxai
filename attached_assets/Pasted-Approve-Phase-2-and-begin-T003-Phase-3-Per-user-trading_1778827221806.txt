Phase 3C — Map EA heartbeat token to user:
Update bridge heartbeat handling so when the EA posts:

Header:
X-MT5-Bridge-Token: <token>

The backend should:
1. Hash the incoming token.
2. Find matching mt5_connections.bridgeTokenHash.
3. Update only that user’s connection record.
4. Save heartbeat/account data to that user’s connection.
5. Mark the connection connected if heartbeat is fresh.
6. If token is invalid, reject safely.
7. If token matches old global/system token, treat it as system/demo bridge only, not personal user data.
