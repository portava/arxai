Phase 7F — Pre-trade checklist engine:
Build a checklist score before a paper trade is opened.

A pre-trade check should evaluate:
- Is there a selected playbook?
- Is the symbol allowed by the playbook?
- Is the session/timeframe aligned?
- Is stop loss defined?
- Is take profit defined?
- Is risk amount acceptable?
- Is reward-to-risk acceptable?
- Did the user write a reason for entry?
- Are required confirmation rules met?
- Are avoid rules triggered?
- Is the user revenge trading or overtrading based on recent session behavior?

Output:
- score 0–100
- decision: pass / warning / block
- failed rules
- passed rules
- improvement note

Important:
A block decision must block PAPER trade opening only inside the app workflow unless user overrides with a note. It must never interact with real broker execution.
