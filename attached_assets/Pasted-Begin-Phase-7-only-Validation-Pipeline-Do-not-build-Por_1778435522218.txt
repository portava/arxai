Rules:
- Nothing can jump directly to live trading.
- Every strategy, rule, and agent behavior must pass staged validation.
- Validation stages:
  - BACKTEST
  - WALK_FORWARD
  - SHADOW_MODE
  - PAPER_TRADING
  - MICRO_LOT_LIVE
  - LIMITED_LIVE
  - FULL_GOVERNED_LIVE
- Failed systems are demoted.
- Edge decay triggers review.
- Risk Governor can freeze promotion.
- Control Tower controls rollout stage.
- All validation decisions must be logged into the Black Box Vault.
- Replay Lab results must influence validation scoring.
- Execution Intelligence must influence validation scoring.
- Trader DNA and Cognitive Risk must influence validation scoring.
- No full live auto-execution yet.

Promotion requirements:
- minimum sample size
- positive expectancy
- acceptable max drawdown
- acceptable losing streak
- confidence calibration score
- execution quality score
- risk compliance score
- survival score
- low false approval rate
- low false block rate

Acceptance criteria:
- System can validate strategies by stage.
- System can promote, demote, freeze, or retire a strategy.
- Live readiness score is explainable.
- Failed validation creates a report.
- All previous phase tests still pass.

After Phase 7, stop and report:
1. Files created
2. Validation stages implemented
3. Promotion/demotion rules added
4. Live readiness scoring added
5. Tests passed/failed
6. Whether Phase 8 is safe to begin
