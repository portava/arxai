- Synthetic volatility can run 24/7.

6. /server/brain/scoring/confluenceScoring.ts

Create a final score engine.

Final confidence score should combine:
- technicalScore
- macroScore
- sessionScore
- newsRiskPenalty
- volatilityPenalty
- spreadPenalty
- strategyMatchScore

Formula:
confidence =
technicalScore * 0.45 +
macroScore * 0.20 +
sessionScore * 0.10 +
strategyMatchScore * 0.15 -
newsRiskPenalty -
volatilityPenalty -
spreadPenalty

For synthetic volatility:
confidence =
technicalScore * 0.65 +
strategyMatchScore * 0.25 +
sessionScore * 0.05 -
volatilityPenalty -
spreadPenalty

7. /server/brain/marketBrain.ts

Create function analyzeMarket(symbol, candles, accountState, settings).

It should call:
- technicalEngine
- macroEngine
- sessionEngine
- newsRiskEngine
- confluenceScoring
- riskManager

Return final decision:

{
 symbol,
 category,
 direction,
 confidence,
 entry,
 stopLoss,
 takeProfit,
 riskReward,
 strategy,
 marketCondition,
 technicalBias,
 macroBias,
 session,
 newsRisk,
 riskApproved,
 blockedReason,
 reasons,
 timestamp
}

Important rules:
- WAIT is a strong valid result.
- Do not force BUY/SELL.
- If confidence is below minimum, return WAIT.
- If risk manager blocks trade, return WAIT.
- If newsRiskEngine says blockTrading, return WAIT.
- If market is choppy, return WAIT unless mean reversion strategy is enabled.
- For Volatility 75 1s, require higher confidence than normal.
- For US30, block trades during major U.S. news unless user disables filter.
