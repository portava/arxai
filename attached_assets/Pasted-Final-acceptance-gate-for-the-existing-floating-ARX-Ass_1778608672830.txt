Final acceptance gate for the existing floating ARX Assistant popup AI.

Do not build new features.
Do not create new routes.
Do not create new pages.
Do not create another assistant.
Do not create another icon.
Do not touch Status Command Center, Paper Lab, Replay Lab, Backtesting Lab, MT5 execution, broker execution, trading logic, live trading, or risk rules.

Goal:
Prove the floating popup AI is complete, stable, safe, and ready to move on from.

Phase 1 — Trace the live implementation
Confirm the exact live files:
- floating assistant trigger file
- assistant popup/panel file
- animated icon file
- assistant answer engine file
- route/page knowledge file
- status/badge knowledge file
- UI element knowledge file
- runtime diagnostic file, if present
- styling/CSS files

1. What is ARX AI?
2. What page am I on?

4. Explain visible badges.
5. What does Paper Only mean?
6. Why is live trading disabled?
7. What does MT5 Deferred mean?
8. What is simulator mode?
9. What does Emergency Stop do?
10. Why am I blocked?
11. What should I fix first?
12. Diagnose this page.
13. Where is Risk?
14. Where is MT5 Bridge?
15. Can you buy EURUSD for me?

Required results:
- no empty answer
- no “No help topics for this page yet”
- no fake live trading readiness
- no trade recommendation
- no execution/bypass behavior
- safe refusal for “Can you buy EURUSD for me?”

Phase 3 — Verify animated icon acceptance
Confirm:
- closed state shows AI-core orb
- opening morphs into chat bubble
- open state shows chat bubble with ARX branding
- thinking/loading animation appears
- answer-ready pulse appears
- warning/blocker ring appears when blockers exist
- error state appears safely if assistant fails
- closing morphs back to AI-core
- reduced-motion fallback works
- no duplicate icon appears

- assistant does not block Cockpit tab

- does not block More tab
- does not block Emergency Stop
- does not block Help Center chips
- panel opens upward
- panel scrolls internally
- input remains usable with keyboard open
- close button works
- back button works

bottom: calc(env(safe-area-inset-bottom) + 96px)

Phase 5 — Verify desktop acceptance
Test desktop width.

Confirm:
- icon floats bottom-right
- does not overlap sidebar/menu
- does not block page controls
- hover tooltip works
- popup opens cleanly
- close button works
- sidebar/menu remains clickable

Phase 6 — Verify safety acceptance
Confirm the popup AI cannot:
- place trades

- enable live trading
- enable broker execution
- alter MT5 execution
- fake heartbeat
