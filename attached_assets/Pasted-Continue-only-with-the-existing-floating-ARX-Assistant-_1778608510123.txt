Phase 2 — Add icon state model
Create a clean icon state model.

Suggested states:
- idle: AI-core orb glow
- hover: stronger glow/pulse
- opening: AI orb morphs into chat bubble

- closing: chat bubble morphs back into AI orb
- thinking: orbit/spinner particles around icon
- typing: subtle wave/three-dot glow
- ready: soft confirmation pulse
- warning: amber ring when blockers/safety issues are active
- error: red ring if assistant/system failed
- disabled: muted icon if assistant unavailable

Do not use the warning/error state to suggest live trading readiness. It should only communicate assistant/app status.

Phase 3 — Connect icon to assistant state
The icon should react to:
- assistant panel open/closed
- assistant is generating/thinking
- assistant has an answer ready
- assistant error
- current active blockers if already available
- current app mode: paper/simulator/live-disabled
- missing knowledge fallback if already logged

Examples:
- When user taps icon: orb morphs into chat bubble.
- While assistant is thinking: small rotating cyan particles.
- When answer is ready: one soft cyan pulse.
- When blockers are active: subtle amber outer ring.
- If assistant fails: subtle red outer ring with accessible label.
