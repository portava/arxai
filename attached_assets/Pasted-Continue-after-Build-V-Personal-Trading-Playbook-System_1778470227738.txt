5. Add rules:
- Do not label edge as STRONG_EDGE without enough sample size.
- If sample size is low, status must be INSUFFICIENT_DATA.
- If expectancy is negative, status should be WEAK_EDGE or NO_EDGE.
- If win rate is high but R:R is poor, warn user.
- If profitability depends on one lucky trade, warn user.
- If edge only works in specific market conditions, clearly show that.
