Do not change code yet.
Do not add providers yet.
Do not rewrite the feed system yet.
This is discovery only.

Goal:
Find every API, provider, feed, bridge, env key, service, endpoint, hook, and UI surface currently involved in ARX market data, chart candles, quotes, scanner results, Ruby analysis, live execution, account totals, and open trades.

- quote
- ticks

- scanner

- Provider actually used
- Fallback provider
- Source label shown to UI

- Stale rules
- Whether Ruby can use it

For each provider, report:

- used by chart: yes/no

Look for:

Report every mismatch.
