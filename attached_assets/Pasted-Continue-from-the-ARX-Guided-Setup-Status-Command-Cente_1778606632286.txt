Continue from the ARX Guided Setup + Status Command Center.

Now build the ARX Paper Trading Practice Lab.

Goal:
Create a complete safe paper/simulator trading environment where users can practice entries, exits, risk sizing, journaling, replay, and performance review without sending any live broker orders.

This is a paper/simulator-only upgrade.
Do not enable live trading.
Do not change live broker execution logic.
Do not alter MT5 order sending.
Do not bypass risk controls.
Do not fake broker connection, heartbeat, readiness, or account safety.

Phase 1 — Create Paper Trading Practice Lab page
Create or upgrade a route/page called:

“Paper Trading Practice Lab”

Purpose:
A safe place where users can simulate trades, practice entries, review results, and improve discipline before live trading is ever considered.

The page should show:
- Current mode: Paper / Simulator
- Selected symbol
- Sim engine status
- Paper-only status
- Live trading disabled status
- Broker execution disabled status
- Readiness status
- Risk status
- Open paper trades
- Closed paper trades
- Daily paper P/L
- Win/loss count
- Risk used
- Safest next step

Phase 2 — Create paper order ticket
Add a paper-only order ticket.

Fields:
- Symbol
- Direction: Buy / Sell
- Entry type: Market simulation / Limit simulation
- Entry price
- Stop loss
- Take profit
- Position size
- Risk percentage
- Notes / trade thesis
- Strategy tag
- Session tag: London / New York / Asia / Custom
- Confidence rating
- Emotional state before trade

Buttons:
- Preview Paper Trade
- Place Paper Trade
- Cancel
- Reset

Hard rule:
This order ticket must never call live broker execution or MT5 order send functions.

Phase 3 — Add risk validation before paper trade
Before a paper trade can be placed, validate:
- stop loss exists
- take profit exists or user confirms no TP for practice
- position size is valid
- risk percentage is within allowed paper risk rules
- account simulation balance exists
- selected symbol exists
- live trading remains disabled
- broker execution remains disabled
- emergency stop is not blocking all practice, if that is how the app defines it
- readiness state is explained clearly

If blocked, show:
- blocker reason
- safety explanation
- suggested fix
- related page button

Phase 4 — Create simulated execution engine
Create a paper/simulator execution service.

It should support:
- opening a simulated trade
- closing a simulated trade
- updating unrealized P/L
- stop loss hit simulation
- take profit hit simulation
- manual close
- cancel pending simulated order
- trade status: pending / open / closed / canceled / blocked

Use simulated price data already available in the app if present.
If no live price feed exists, use the existing simulator price source or clearly show “simulation price only.”

Do not use real broker execution.

Phase 7 — Add entry practice / snipe drill mode
Create a practice mode called:

“Snipe Entry Drill”

Purpose:
Help the user practice waiting for the best entry window based on their selected trading style.

The drill should include:
- selected symbol
- selected session
- selected trading style: scalping / intraday / swing / custom
- setup checklist
- entry confirmation checklist
- simulated entry timing score
- risk/reward score
- patience score
- discipline score
- result review after close

The app should evaluate:
- Did the user wait for confirmation?
- Was stop loss logical?
- Was risk controlled?
- Was entry too early?
- Was entry too late?
- Was reward worth the risk?
- Did the user follow their plan?

Do not tell the user what to buy or sell.
Do not generate live trade signals.
Frame this as training and review only.

Phase 8 — Add AI Coach review for paper trades
After a paper trade closes, ARX Assistant / Coach should review it.

Coach should explain:
- what the user planned
- what happened
- whether risk was controlled
- whether the trade followed the stated plan
- what was disciplined
- what could improve
- one practical lesson
- one rule to remember next time

Coach must not say:
- “You should buy now”
- “You should sell now”
- “Take this live”
- “Live trading is safe”

Safe wording:
“This is a paper/simulator review. Use it to improve discipline before considering any real-money environment.”
