Build ARX Pattern Sync System for synthetic indices.

Goal:
Create a multi-symbol pattern comparison engine that helps ARX identify when Deriv synthetic indices are moving in the same structure across timeframes. The system should compare V25(1s), V50, V50(1s), V75, V75(1s), and any supported volatility symbols. It should detect which chart is leading, which charts are following, which are lagging, and whether the shared setup is bullish continuation, bearish continuation, pullback, reversal, consolidation, or fakeout risk.

Core concept:
The user manually identified that V25(1s) and V75 were showing the same pattern:
- major drop or bottoming structure
- base/chop
- aggressive bullish breakout
- pullback near highs
- possible continuation if support holds

V75 looked cleaner/stronger. V25(1s) was bullish but weaker/pulling back. V50 was similar but not confirmed. V50(1s) showed a strong rally followed by a short-term pullback.

Build this knowledge directly into ARX.

Pattern match logic:
Charts are considered “same pattern” when they share most of these conditions:
- same higher-timeframe bias
- same recent swing structure
- similar breakout/pullback sequence
- similar support/resistance behavior
- similar momentum direction
- similar candle compression or expansion behavior
- similar recovery from bottom or rejection from top

3. Add timeframe logic.

Pattern Sync must compare both:
- H4 for big-picture direction
- M15 for entry timing

H4 should answer:
- Is the chart bullish, bearish, ranging, or reversing?
- Did it break major structure?
- Is it holding above breakout support?
- Is it near exhaustion?

M15 should answer:
- Is the entry timing clean?
- Is price pulling back?
- Is price breaking lower/higher?
- Is the move already extended?
- Is the trader late?

ARX should never recommend confidence from M15 alone if H4 disagrees.

- V75 = Market Leader

Return readable output like:

6. Add scoring.

Use 0–100 scores.

Pattern Match Score:
- 80–100 = same pattern strongly confirmed
- 60–79 = similar but weaker
- 40–59 = partial match / confirmation needed
- below 40 = not same pattern

Clean Setup Score:
Reward:
- clear higher highs/higher lows for bullish
- clean lower highs/lower lows for bearish
- breakout plus support hold
- pullback into structure
- aligned H4 and M15

Penalize:
- chop
- wick-heavy candles
- late entries after extended move
- price trapped between support/resistance
- H4/M15 disagreement
- price near exhaustion top/bottom

Fakeout Risk Score:
Increase risk when:
- price breaks resistance but closes back below
- price breaks support but reclaims quickly
- candles have large wicks
- current price is near major opposing level
- the symbol is lagging while leader already moved
- M15 entry is opposite H4 structure

12. Add safety rules.

ARX must not auto-trade only because Pattern Sync matches.

Pattern Sync can increase confidence only when:
- H4 and M15 align
- current symbol is not lagging too far behind
- fakeout risk is acceptable
- price is not extended into resistance/support
- spread/bridge/feed freshness checks pass
- existing ARX risk rules pass

Hard rule:
Pattern Sync is an analysis layer, not an execution bypass.

Do not allow Pattern Sync to skip:
- live approval
- one-click confirmation
- kill switch
- risk limits
- broker heartbeat
- feed freshness
- max drawdown checks
- emergency stop
