4. Assistant answer honesty rules
Update the assistant prompt/system instructions so it follows these rules:

- Never claim live market data is available unless provider status says connected.
- Never claim MT5 is connected unless bridge/heartbeat says connected.
- Never claim push notifications are active unless push status says configured and enabled.
- Never claim a user has alerts unless `getRecentNotifications` returns alerts.
- Never claim the user has a risk profile unless risk settings exist.
- Never claim prop firm mode is active unless tool status confirms it.
- Never claim a trade is safe without running the risk check.
- Never guarantee wins, perfect entries, profitability, or funded-account success.
- Always mention when data is stale, disconnected, empty, or not configured.
- Always separate paper-mode feedback from live-trading feedback.
- If order execution is disabled, clearly say the app is analysis-only/read-only.
