PART 2 — Enforce MT5-confirmed open-position rule

Open Positions must be based on the latest MT5 open-position snapshot.

Rules:

1. A position can appear under “Open Positions” only if it has a matching real MT5 open position.
2. Matching should use MT5 ticket/position ID where available.
3. If no ticket/position ID exists, match by broker-provided position identifier only if reliable.
4. ARX-only draft/pending records must not appear under Open Positions.
5. Reconciled records must not appear under Open Positions.
6. Failed/rejected records must not appear under Open Positions.
7. Old seeded/test/demo records must not appear under live Open Positions.
8. Manual MT5 positions may appear only if they are real MT5 positions and clearly labeled “Manual MT5 / Unassigned” until attributed.

PART 4 — Add live P/L to every position

Every open position row/card must show live P/L.

5. show account currency

PART 5 — Reconcile ARX vs MT5 positions

Implement or repair reconciliation.

On each MT5 sync:

1. Pull all real MT5 open positions.
2. Compare against ARX active positions.
3. If MT5 has position and ARX has no record:
    * create manual/unattributed admin-visible record
    * source = Manual MT5
    * do not expose to normal users unless attributed
4. If ARX has active position and MT5 has no match:
    * mark as reconciled / broker-closed / orphan-resolved
    * remove from Open Positions
    * preserve audit trail
5. If ARX has position and MT5 has match:
    * update entry, current price, P/L, SL, TP, lot, open time, ticket
6. If MT5 position closed:
    * mark closed with close time/price/P&L if available

PART 6 — Fix allocation exposure calculations

Rules:

2. Reconciled/phantom/orphan records must not reduce available allocation.

4. If manual MT5 positions are unattributed, admin should see them but user allocations should not be randomly charged.
5. Available allocation must recalculate after reconciliation.
