==================================================
5. CLASSIFY BUGS
==================================================

Create or update issues in /admin/issues.

Use this priority system:

P0 Critical:
- app cannot load
- owner locked out
- full tester access broken
- risk governor missing
- kill switch missing
- simulator trade crashes
- live tester workflows inaccessible
- MT5 falsely shown as connected
- real broker execution falsely shown as available
- secrets exposed

P1 Major:
- route broken
- API broken
- journal/calendar not updating
- OMS not recording
- AI card generation broken
- live intent queue broken
- mobile navigation broken
- audit logs missing

P2 Normal:
- bad UI state
- layout issue
- missing empty state
- unclear label
- slow loading
- chart fallback missing

P3 Minor:
- copy polish
- small visual spacing
- tooltip improvement

Fix all P0 and P1 issues immediately.
Fix P2 issues if quick.
Leave P3 issues in known issues.
