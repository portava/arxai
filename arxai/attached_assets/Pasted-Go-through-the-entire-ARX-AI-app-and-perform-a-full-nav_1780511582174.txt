Go through the entire ARX AI app and perform a full navigation/menu consolidation audit.

The goal is to reduce clutter by merging similar features, reducing unnecessary menu items, and organizing related pages into clean tabbed sections. Do not remove features. Do not rebuild the app. Do not redesign the full UI yet. This phase is only for structure, organization, navigation cleanup, and clutter reduction.

MAIN GOAL

The app currently has too many separate pages, menu items, repeated sections, and similar tools spread across different areas. Consolidate similar features into fewer, clearer destinations using tabs, collapsible sections, and grouped panels.

The app should feel cleaner and easier to navigate before the next UI polish pass.

IMPORTANT RULES

* Do not delete active features.
* Do not break existing routes, backend logic, permissions, admin gates, Ruby, Scanner, live trading controls, MT5 bridge, agent governance, scalp engine, or risk systems.
* If a feature is active, preserve it and move it under the correct grouped section.
* If a feature is dormant, duplicated, unused, or unclear, flag it in the cleanup report instead of deleting it unless it is obviously dead/test-only code.
* Keep admin-only features hidden from normal users.
* Do not expose backend names, route names, raw function names, schema names, or developer wording to users.
* The goal is less clutter, not fewer capabilities.

PHASE 1 — FULL APP NAVIGATION AUDIT

Inspect every app page, route, sidebar item, bottom menu item, header button, floating menu, drawer item, admin page, user page, scanner page, Ruby panel, trade panel, settings page, and dashboard section.

Create a map of all current visible navigation items and group them into logical categories.

Identify:

* duplicate pages
* similar tools that should be tabs under one page
* menu items that belong together
* pages that are too long and should become tabbed sections
* features that appear in multiple places unnecessarily
* user-facing items that should be admin-only
* admin-only items that accidentally show to normal users
* labels that are unclear or too technical
* orphaned pages/routes with no useful navigation purpose
* dormant UI sections that take space but do not help users
* repeated alerts, repeated instructions, and repeated explanatory blocks

PHASE 2 — CONSOLIDATE SIMILAR MENU ITEMS

Merge similar features into fewer primary menu destinations.

Recommended structure:

1. Dashboard
    Use for the user’s main account overview:

* account summary
* active positions overview
* market status overview
* recent activity
* Ruby quick insight
* alerts summary

2. Markets
    Merge all market discovery tools here using tabs:

* Focus Scan
* Broad Scan
* Flame Scalp
* Watchlist
* Selected Market Explanation
* Market History / News Context

Do not make each of these separate main menu items if they can live as tabs under Markets.

3. Trade
    Merge trade action tools here using tabs:

* One-Click Scalping
* Manual Trade Ticket
* Pending Orders
* Active Positions
* Close / Modify Trade
* Stop Loss / Take Profit Editor
* Trade History

Trade execution controls should stay clear, but not scattered.

4. Ruby
    Use one main Ruby area instead of multiple scattered assistant panels:

* Ruby Chat
* Market Explanation
* Trade Reasoning
* Voice Mode
* Saved Chats / Memory
* Ruby Settings if needed

Ruby can still appear contextually across the app, but the main Ruby destination should be clean and unified.

5. Risk
    Merge risk-related tools here:

* Risk Score
* Reward-to-Risk
* Stop Loss Logic
* Take Profit Logic
* Exposure
* Account Protection
* Warnings / Caution Flags

6. Intelligence
    Merge AI agent ecosystem tools here:

* Agent Scoring
* Agent Lifecycle
* Governance Court
* Learning Camp
* Agent Factory
* Household Report
* Governance Trace

For normal users, only show plain-language AI confidence/reasoning if appropriate. Full agent controls must remain admin/OWNER only.

7. Admin
    Admin-only destination for:

* user management
* invite codes
* role permissions
* live trading permissions
* broker/master switch controls
* owner live test cycle
* kill switches
* MT5 / Deriv bridge status
* EA download link
* execution logs
* governance/admin traces
* system QA
* environment status

Normal users must not see this.

8. Settings
    Use for:

* profile settings
* account settings
* notification settings
* connection settings
* display/preferences
* security
