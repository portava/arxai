Build JJ = Replay Simulator + Strategy Lab.

Goal:
Create a replay simulator and strategy lab where the system can practice on historical, synthetic, or recorded market scenarios without touching live money.

The simulator should let the AI:
- replay candle-by-candle market movement
- test Build AA decisions in replay mode
- test sniper-entry filters from Build FF
- simulate paper-like entries and exits
- compare setups from the Build II playbook
- identify which setups work, fail, or need review
- generate replay reports that improve coaching and playbook confidence

Important:
Build JJ must NOT place live trades.
Build JJ must NOT enable live trading.
Build JJ must NOT call MT5 live execution.
Build JJ must NOT modify canPlaceTrades.
Build JJ must NOT modify live broker permissions.
Build JJ must run in REPLAY / PAPER_SIMULATION mode only.

Current system:
- Build AA = trade decision orchestrator
- Build BB = auto-debrief
- Build CC = learning feedback engine
- Build DD = read-only market data
- Build EE = paper execution engine
- Build FF = paper autopilot loop
- Build GG = trading calendar + AI command center
- Build HH = risk governor
- Build II = trader coach + playbook generator
- Build JJ = replay simulator + strategy lab

Core requirement:
Build a controlled replay engine that feeds historical/synthetic candles into the decision system, simulates trades safely, and outputs replay performance reports without creating real trades or live orders.

4. Candle-by-candle replay engine

The engine should:
- load a scenario
- step through candles in order
- create a simulated market snapshot for each step
- call Build AA in replay mode
- include replay timestamp instead of live timestamp
- optionally call sniper-entry filter
- open simulated replay trades only when rules pass
- update simulated open trades candle by candle
- close trades when SL/TP/time/manual replay rules trigger
- calculate P&L, drawdown, win rate, and trade quality
