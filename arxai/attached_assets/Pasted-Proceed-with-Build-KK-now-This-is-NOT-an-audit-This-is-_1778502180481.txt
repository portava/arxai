Build KK = Data Import + Broker Read-Only Connector.

Goal:
Create a safe data-import and read-only broker connector layer so the trading system can use better historical candles, imported datasets, account snapshots, symbol info, and read-only broker data without allowing live execution.

The system should be able to:
- import candle data from CSV/JSON/manual payloads
- validate and normalize candle data
- store imported historical data
- turn imported candles into Replay Simulator scenarios for Build JJ
- feed imported candles into Build DD market data when requested
- support read-only broker/account snapshots if credentials are configured
- expose broker symbols, account balance/equity, open positions, and price quotes in read-only mode only
- reject any provider or connector that is not read-only

Important:
Build KK must NOT place live trades.
Build KK must NOT enable live trading.
Build KK must NOT call MT5 live execution.
Build KK must NOT modify canPlaceTrades.
Build KK must NOT modify live broker permissions.
Build KK must NOT create live orders.
Build KK must run in DATA_IMPORT / BROKER_READ_ONLY mode only.

3. Candle validation rules

Validate every candle:

Required fields:
- time
- open
- high
- low
- close
- volume optional

Validation:
- time must be valid date/timestamp
- open/high/low/close must be numeric
- high must be >= low
- high must be >= open and close
- low must be <= open and close
- duplicate timestamps should be detected
- candles must be sortable by time
- gaps should be detected based on timeframe
- extreme outliers should be warned, not always rejected
- empty imports should be rejected
- unsupported timeframe should be rejected
