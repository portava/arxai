Build LL = Notification Center + Safety Alerts.

Goal:
Create a centralized notification and safety-alert system that warns the trader when something important happens across the trading app.

The notification system should alert for:
- Risk Governor blocks
- paper trading paused
- autopilot paused/stopped
- cooldowns active
- daily paper loss limit warnings
- market data degraded/stale/wide spread
- broker read-only safety warnings
- unsafe broker mode attempts
- paper trade opened/closed
- TP/SL hit
- BB auto-debrief created
- CC learning event processed
- repeated mistake pattern detected
- Trader Coach report ready
- Replay/Strategy Lab report ready
- data import validation issues
- system build/integration errors
- live trading attempted or detected, which must become a CRITICAL alert

Important:
Build LL must NOT place trades.
Build LL must NOT enable live trading.
Build LL must NOT call MT5 live execution.
Build LL must NOT modify canPlaceTrades.
Build LL must NOT recommend live trading.
Build LL is alerts, notifications, warnings, and review actions only.

Current system:
- Build AA = trade decision orchestrator
- Build BB = auto-debrief
- Build CC = learning feedback engine
- Build DD = read-only market data
- Build EE = paper execution engine
- Build FF = paper autopilot loop
- Build GG = trading calendar + AI command center
- Build HH = risk governor
- Build II = trader coach + playbook
- Build JJ = replay simulator + strategy lab
- Build KK = data import + broker read-only connector
- Build LL = notification center + safety alerts

Core requirement:
Create one central Notification Center that receives events from AA-KK, stores them, deduplicates spam, ranks urgency, and displays clear next actions to the user.

4. Deduplication and rate limiting

Prevent notification spam.

Rules:
- Same dedupe_key within a short window should update existing notification instead of creating duplicates.
- Critical alerts should never be silently hidden.
- Repeated warnings should increment a count in metadata.
- Snoozed notifications should not reappear until snooze expires unless severity becomes CRITICAL.
- Do not create unlimited alerts from autopilot cycles.
