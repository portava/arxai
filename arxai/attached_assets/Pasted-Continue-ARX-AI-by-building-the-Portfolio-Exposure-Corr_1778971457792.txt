- unrealized P&L

- total open trades
- total open lot size

- total exposure by symbol

- total exposure by asset class
- total exposure by strategy/playbook
- total exposure by routing mode
- total exposure by demo/live account type
- daily drawdown
- weekly drawdown
- max current loss if all SLs hit
- profit currently open
- loss currently open

If MT5/account data is missing, show unavailable instead of fake data.

PART 2 — Correlation Risk Engine

Detect when trades are stacking risk.

Examples:
- multiple USD-based trades
- EURUSD buy + GBPUSD buy may both depend on USD weakness
- XAUUSD buy may be affected by USD/news risk
- multiple trades on same symbol
- multiple trades in same direction
- multiple trades opened during same session
- multiple trades using same strategy
- multiple trades exposed to same news event

Create correlation labels:
- Low correlation risk
- Medium correlation risk
- High correlation risk
- Same-symbol stacking
- Same-currency stacking
- Same-direction stacking
- News-correlated exposure
- Strategy concentration risk
- Data insufficient

PART 7 — Risk Governor Integration

Risk Governor should use portfolio exposure before approving any new trade.

Before a new trade queues, check:
- total open exposure
- same-symbol exposure
- same-currency exposure
- correlated risk
- daily drawdown
- margin risk
- max open trades
- account health score
- shared-master allocation risk

If risk is too high:
- block trade if hard rule
- warn if soft rule
- recommend smaller size if possible
- recommend close-only mode if needed

PART 8 — Shared-Master Support

In SHARED_MASTER_MT5 mode:
- user only sees their own virtual allocation

- user portfolio health is based on their virtual account
