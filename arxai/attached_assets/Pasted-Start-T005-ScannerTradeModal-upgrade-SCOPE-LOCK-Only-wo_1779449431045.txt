GOAL:
When a user taps BUY or SELL from a scanner result, open a clean trade ticket modal that is prefilled with that scanner setup.

The scanner trade flow should feel professional, safe, and simple.

Required behavior:
1. Scanner BUY button says only BUY and is green.
2. Scanner SELL button says only SELL and is red.
3. Tapping BUY opens trade ticket modal with direction = BUY.
4. Tapping SELL opens trade ticket modal with direction = SELL.
5. Modal should prefill:
   - symbol
   - direction
   - timeframe
   - scanner confidence
   - entry zone if available
   - suggested stop loss if available
   - suggested take profit if available
   - risk/reward if available
   - news-risk state
   - historical/backtest summary
6. User must still manually confirm any trade.
7. No trade should be placed by merely opening the modal.

Modal sections:
- Trade Setup
- Position Size / Lot Size
- Stop Loss
- Take Profit
- Risk / Reward
- Historical Check
- News Risk Check
- Ruby Summary
- Final Confirmation

Historical Check should show:
- historical bias
- similar setups found
- win rate if available
- average drawdown
- average time to target
- confidence/sample size
- history unavailable state if missing

News Risk Check should show:
- news risk: none / low / medium / high / critical
- related event/headline if available
- bias: bullish / bearish / mixed / unclear
- recommendation: Watch / Wait / Avoid / No Trade
- news unavailable state if missing

- If technical setup conflicts with news, show warning.
- If historical sample is weak, show lower confidence warning.
- Do not block trades unless existing risk rules already block them.
- If existing risk rules block it, show clean blocked reason.
