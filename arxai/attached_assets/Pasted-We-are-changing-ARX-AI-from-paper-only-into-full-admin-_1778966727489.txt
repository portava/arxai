D. Backend trade guard

Every trade request must pass this exact guard chain:

1. User is authenticated.
2. User owns the MT5 connection.
3. Global platform mode is not off.
4. Emergency stop is false.
5. User trading is enabled.
6. User is not suspended.
7. User account type matches platform mode:
   - DEMO_TRADING only executes on demo MT5 accounts.
   - LIVE_TRADING only executes on live MT5 accounts.
8. MT5 bridge token is valid.
9. Risk limits pass.
10. Duplicate command check passes.
11. Command expiration check passes.
12. Live disclosure accepted if platform mode is live.
13. Explicit confirmation exists for live orders.
14. Audit log is written.
15. Command is queued only for that user and that MT5 connection.

For live account:
