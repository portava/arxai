Heat calculation:
Market heat should combine:
1. Price movement / momentum
2. Volatility
3. Relative strength
4. News sentiment / risk
5. Economic-calendar impact
6. Session context
7. Data freshness

Suggested formula:
price_heat = normalized price momentum and relative strength
volatility_heat = current volatility vs recent baseline
news_heat = sentiment/risk score from news headlines
calendar_heat = upcoming high-impact event risk
freshness_penalty = downgrade if stale/delayed/provider missing

final_heat_score =
  weighted(price_heat, news_heat, calendar_heat, volatility_heat)
  minus freshness_penalty

Rules:
- If price data is unavailable, heat cannot be high-confidence.
- If news/calendar provider is missing, show “news unavailable,” not “low news risk.”
- If both price and news are unavailable, show unavailable/gray state.
- If only price exists, label “price-only heat.”
- If only news exists, label “news-only heat.”
- If both exist and fresh, label “confirmed heat.”
- If data is stale, heat can display but must be capped to low confidence.
