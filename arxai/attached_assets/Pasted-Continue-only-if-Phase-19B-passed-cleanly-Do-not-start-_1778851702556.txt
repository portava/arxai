PHASE 20A GOAL:
Audit the existing trade setup, trade plan, entry timing, strategy, scoring, AI coaching, and trading-style systems first. Then adjust only what is missing or broken so ARX AI can evaluate paper/demo trade plans and help users improve entries safely.

This phase should create a disciplined trade-coaching layer, not a profit-prediction system.

ARX AI should help answer:
- Is this trade plan complete?
- Is the setup aligned with the user’s rules?
- Is risk acceptable?
- Is the timing reasonable based on available data?
- What is missing before entry?
- What should the trader wait for?
- Why was this setup weak?
- How can the user improve discipline?

ARX AI must never say:
- “This trade will win.”
- “This is the perfect entry.”
- “Enter now” based on fake or unavailable data.
- “Guaranteed profit.”
- “Risk more.”
- “Bypass paper-only.”

STEP 4 — Build or repair setup scoring model

If a setup scoring model already exists, improve it.

If missing, add a safe scoring model for paper/demo trade plans only.

Suggested scoring categories:

1. Plan completeness
- symbol present
- direction present
- entry present
- stop loss present
- take profit present
- trade thesis present
- setup type present

2. Risk quality
- risk amount known
- stop loss distance valid
- position size valid
- risk within user settings
- daily loss rule respected
- prop firm rule respected if configured

3. Reward quality
- take profit exists
- risk/reward can be calculated
- R:R meets user minimum if configured
- trade has clear invalidation

4. Timing readiness
- session/time context known
- market data connected or manual context provided
- user confirms entry trigger
- no fake live timing claims

5. Discipline alignment
- trade follows user strategy rules if configured
- user did not override risk warnings
- setup includes notes/reasoning
- journal history considered only if real history exists

Output should be a transparent score, not a prediction.

Example labels:
- Incomplete plan
- Needs review
- Risk warning
- Watchlist-ready
- Paper-trade ready
- Blocked by risk
- Blocked by liveLocked
