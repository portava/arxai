2. TEST CYCLE RULES
When OWNER starts a Live Test Cycle:

Step A — Preflight:
- Confirm OWNER is signed in.
- Confirm mode is Live or Live Shared.
- Confirm bridge heartbeat is fresh.
- Confirm master bridge is pinned.
- Confirm broker execution env AND operator switch are true.
- Confirm kill switch is released.
- Confirm EA reports:
  - EnableLiveExecution=true
  - ReadOnlyMode=false
  - allowOrderExecution=true
  - marketOrdersSupported=true
- Confirm the 16-gate evaluator passes.
- Confirm no existing ARX live test trade is still open.
- Confirm symbol is MT5-tradable.
- Confirm current balance is enough for broker minimum margin.

Step B — Open:
- Use one tiny test trade.
- Default symbol: EURUSD unless OWNER selects another MT5-tradable symbol.
- Default lot: smallest broker-supported lot, normally 0.01.
- Default side: BUY unless OWNER selects SELL.
- Use market order only for first test cycle.
- Add SL and TP if the app can calculate them.
- If SL/TP are omitted because OWNER unrestricted profile allows it, show clear warning but allow only after owner confirmation.
- Insert exactly one live command only after OWNER confirms the test cycle.

Step C — Verify:
Track:
- command inserted
- EA pulled command
- broker accepted/rejected
- MT5 ticket/order id
- fill price if available
- current P/L
- error/rejection reason if failed

Step D — Auto-close:
After the trade is confirmed open, automatically queue a close command for that same ticket.

Close timing:
- Close immediately after broker confirms open
OR
- Close after 5–15 seconds if needed to verify open position snapshot

Do not leave the test trade open unless close fails.

Step E — Confirm close:
Track:
- close command inserted
- EA pulled close command
- broker closed/rejected
- close ticket/result
- realized P/L
- full cycle time

3. AUTO-CLOSE PROTECTION
If close fails:
- Do not open another test trade.
- Show critical alert:
  “Test trade opened but auto-close failed. Manual close required in MT5.”
- Show MT5 ticket id and symbol.
- Keep the cycle locked until trade is confirmed closed or admin marks it resolved.
- Audit the failure.

If EA heartbeat becomes stale after opening:
- Stop new commands.
- Show critical alert.
- Tell operator to close manually in MT5 if auto-close cannot be confirmed.
