Continue from the ARX Assistant App Brain and QA validation pass.

Now upgrade ARX Assistant into a true in-app ARX Guide.

Goal:
The assistant should not only answer questions. It should understand what page the user is on, what status badges are active, why actions are blocked, and what the safest next step is. It should guide the user through the app without giving trading advice or bypassing safety systems.

Phase 1 — Add “What am I looking at?” mode
Create a global assistant shortcut called:
“What am I looking at?”

When clicked, the assistant should explain:
- current page name
- purpose of the page
- visible status badges
- active safety locks
- main buttons/controls on the page
- what the user can do safely from this page
- what is currently blocked and why
- recommended next app step

Example response:
“You are on the Help Center page. This page explains ARX safety systems and app blockers. Your app is currently in Paper Only mode, Live Trading Disabled, Live Broker Execution Disabled, and MT5 Deferred / Simulator Mode. That means the system can explain and simulate workflows, but it cannot send live broker orders. Safest next step: review readiness, confirm MT5 heartbeat, then use paper/simulator mode only.”

Phase 2 — Add “Why am I blocked?” diagnostic engine
Build a blocker diagnosis system that checks current app state and returns a clear explanation.

It should inspect:
- paper only mode
- live trading disabled
- broker execution disabled
- MT5 deferred
- simulator mode
- broker read-only
- missing heartbeat
- readiness failures
- emergency stop status
- user permission level
- incomplete setup
- missing secrets/config
- disconnected bridge
- disabled autopilot
- risk lock conditions

The assistant should answer:
- what is blocked
- why it is blocked
- which safety system caused it
- whether the block is protective or an error
- what page to open next
- what not to do
- whether live trading remains unavailable

Important:
Never tell the user to bypass a safety lock. Explain how to resolve setup/readiness properly.

Within the current app session, the assistant should remember the last few assistant questions and answers so follow-ups work.

Example:

User: “How do I fix it?”
Assistant should know “it” means MT5 deferred.

Do not store sensitive data permanently.
Do not store broker credentials, API keys, account numbers, or secrets.

The assistant must refuse or redirect if the user asks:
- What should I buy?
- Should I enter EURUSD now?
