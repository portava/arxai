SECTION 2 — Pivot Points

Define Pivot Points:
Objective price levels calculated from prior period high, low, and close. They act as possible support/resistance and direction-change zones.

Add PivotTruth module.

PivotTruth should calculate:
- classic pivots
- Fibonacci pivots optional
- Camarilla pivots optional
- Woodie pivots optional

Start with classic pivots:
Pivot = (High + Low + Close) / 3
R1 = 2 × Pivot - Low
S1 = 2 × Pivot - High
R2 = Pivot + (High - Low)
S2 = Pivot - (High - Low)
R3 = High + 2 × (Pivot - Low)
S3 = Low - 2 × (High - Pivot)

PivotTruthVerdict:
- pivotSourceTimeframe: daily / weekly / monthly / session
- pivot
- r1
- r2
- r3
- s1
- s2
- s3
- currentZone:
  - above_pivot
  - below_pivot
  - at_pivot
  - at_support
  - at_resistance
  - between_levels
  - breakout_zone
  - rejection_zone
- nearestLevel
- distanceToNearestLevel
- pivotBias: bullish / bearish / neutral / mixed
- reactionStatus:
  - approaching
  - rejecting
  - holding
  - breaking
  - retesting
  - failed_break
- confidence
- warnings[]

Pivot behavior:
- Above pivot = bullish lean, not buy permission.
- Below pivot = bearish lean, not sell permission.
- At pivot = decision zone.
- At R/S level = reaction zone.
- Breakout through R/S requires close + momentum + follow-through.
- Rejection from R/S requires wick/reversal/failed close confirmation.
- If target is too close to next pivot level, cap quality.
- If price is stuck between levels, mark as no-edge or wait.
- If price already moved from pivot to R2/R3 or S2/S3, check exhaustion/too-late.

Pivot integration:
Scanner should show:
- nearest pivot level
- distance to level
- pivot bias
- reaction status
- target room

Eleanor should explain:
- “Price is above the daily pivot, so bullish pressure has context, but entry still needs confirmation.”
- “Price is approaching R1, so buying here has limited room unless R1 breaks cleanly.”
- “Price rejected S1, which supports a conditional bounce setup.”

- If pattern is forming but unconfirmed, direction stays conditional.
- If feed is limited/stale, direction is context-only.

SECTION 5 — Order Flow

Create OrderFlowTruth module.

Definition:
Order flow measures buying/selling pressure using available market data. Where true Level 2/depth/tape is unavailable, use proxy order-flow metrics and label them honestly.

OrderFlow data tiers:

Tier 1 — True order flow if available:
- bid/ask depth
- market depth
- volume at price
- aggressive buys/sells
- delta
- cumulative delta
- spread
- liquidity imbalance
- iceberg/absorption signals if available

Tier 2 — Proxy order flow:
- tick volume
- candle body/wick pressure
- volume spike
- spread widening
- momentum impulse
- rejection candles
- liquidity sweep behavior
- bid/ask quote movement if available

Tier 3 — Not available:
- no volume/depth/proxy reliable enough
- mark order flow unavailable
- do not fake it

OrderFlowTruthVerdict:
- dataTier: true_order_flow / proxy_order_flow / unavailable
- pressure: buying / selling / balanced / mixed / unknown
- strength: weak / moderate / strong
- absorptionDetected
- imbalanceDetected
- spreadCondition: normal / wide / unstable / unknown
- volumeCondition: low / normal / high / spike / unknown
- liquiditySweep:
  - detected
  - side: buy_side / sell_side
  - reclaimed
- supportsDirection: yes / no / mixed / unknown
- confidence
- warnings[]

Order flow rules:
- If true depth is unavailable, UI must say proxy order flow.
- Proxy order flow cannot be treated as institutional order flow.
- Wide spread downgrades entry quality.
- Low liquidity downgrades timing.
- Strong rejection at pivot/support/resistance can support reversal thesis.
- Strong buying into resistance may still be dangerous if no breakout close.
- Strong selling into support may still be dangerous if no breakdown close.
- Absorption at a level should trigger caution.
- Order flow contradiction caps Scanner/Scalp confidence.

Timing rules:
- Do not confirm breakout on a still-forming candle unless strategy explicitly allows intrabar scalp mode.
- If signal is old, mark late/missed.
- If price is far from trigger, mark chase/too-late.
- If major news is near, block or downgrade.
- If spread is wide, block or downgrade.
- If session is illiquid for that symbol, downgrade.
- If volatility is extreme, require wider risk or no trade.
- If compression is forming, wait for expansion/break.
- If expansion already happened, check exhaustion.
