T019 — SYSTEM-WIDE OWNER-APPROVED LIVE TRADING UNRESTRICTED MODE VIA ADMIN RISK GOVERNANCE

Current issue:
ARX AI is still enforcing restrictions across the app that I did not personally set in Admin Risk/Governance. This makes live trading harder than it should be. ARX is a LIVE trading app. If I want a restriction, I will set it myself in the admin risk setup.

Owner instruction:
Remove all app-added live trading restrictions system-wide unless they are explicitly enabled in Admin Risk/Governance.

This applies across the entire app:

1. Scanner
2. Trade page
3. Chart trading
4. Ruby actions
5. Admin trade tools
6. One-click / Single Confirm
7. Live shared master bridge
8. Trade modal
9. Pending orders
10. Close / partial close / reverse / break-even actions
11. Symbol search
12. Any live execution path
13. Any backend live dispatch path
14. Any frontend validation path

Product direction:
ARX AI is LIVE-first.
Do not use Demo.
Do not use Paper Trading.
Do not use fake execution.
Do not use simulated trade data.
Do not fabricate MT5 tickets.
Do not claim success unless MT5 confirms.
Do not add training wheels unless Admin Risk/Governance turns them on.

This is not a rebuild.
Do not redesign the app.
Do not duplicate trading systems.
Do not reset live broker execution config.
Do not weaken auth, owner/admin identity, user ownership, master-account privacy, MT5 connection truth, broker validation, or MT5 confirmation.

Core rule:
The only restrictions that should block owner/admin LIVE trading are:

A. Non-negotiable technical/security truth checks:

1. User must be authenticated.
2. User must be owner/admin or explicitly live-approved.
3. Request must be tied to the correct ARX user/account.
4. Trade must be recorded in the ARX ledger.
5. Server-side user ownership filtering must remain.
6. Normal users must not see other users’ trades.
7. Master account data must not leak.
8. MT5 bridge must be connected.
9. EA/terminal must be connected.
10. Broker symbol must exist and be tradable.
11. Broker lot rules must be valid.
12. Broker precision/tick rules must be valid.
13. Broker must accept the order.
14. MT5 must return a real ticket/order/position/deal ID.
15. ARX must not show success before MT5 confirms.
16. No Demo/Paper/fake fallback.

B. Restrictions I personally enable in Admin Risk/Governance:
Everything else must be configurable and default OFF for owner/admin unrestricted live trading.
