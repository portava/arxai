Fix ARX MT5 live-feed detection so real mirrored broker candles are not mislabeled as historical/limited.

Problem:
ARX is showing scanner/chart data for BOOM1000 and other symbols, but labels the feed as “historical only,” “live feed unavailable,” “analysis only,” or “feed limited.” The user reports this is mirroring what is visible on MT5. If the candles are truly coming from the MT5 bridge/broker in real time, ARX must classify them as broker-confirmed live feed, not historical-only. The current state breaks the app by blocking entries and making scanner/chart output look unusable.

Scope:
This task is to audit and fix feed-source/freshness classification only. Do not weaken live execution gates. Do not allow trades from stale, synthetic, fallback, or historical-only data. Do not bypass the 18 live dispatch gates. Instead, make the feed classifier accurately distinguish real MT5 live candles from fallback/historical candles.

Do not label MT5 broker candles as historical-only.

4. Fix freshness logic

  - symbol feed stale

A global bridge heartbeat alone is not enough. A symbol should be live-entry eligible only when its own price/candle feed is fresh.
