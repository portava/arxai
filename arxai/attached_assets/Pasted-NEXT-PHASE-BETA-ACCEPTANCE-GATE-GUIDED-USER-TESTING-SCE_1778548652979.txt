NEXT PHASE: BETA ACCEPTANCE GATE + GUIDED USER TESTING SCENARIOS

Goal:
Run real owner/tester acceptance scenarios from start to finish and determine if the app is actually usable as a beta.

Do not add new trading features.
Do not fake MT5 connection.
Do not place real broker orders.
Do not claim broker fills.
Do not expose secrets.
Do not block owner tester access.
Keep MT5 deferred until the desktop/VPS bridge is connected later.

==================================================
1. VERIFY PREVIOUS QA STATUS FIRST
==================================================

Before running acceptance testing, check:

- /api/release/readiness
- /api/system/full-health
- /api/admin/issues
- /api/auth/permissions
- /api/broker/status

If any P0 or P1 issue remains, stop and fix it first.

P0/P1 blockers include:
- owner locked out
- full tester access broken
- app route crash
- simulator trade crash
- live tester workflow inaccessible
- risk governor missing
- kill switch missing
- MT5 falsely shown as connected
- real broker execution falsely available
- secrets exposed

Only proceed if:
- owner full tester access works
- app loads
- simulator works
- live tester workflows are visible
- MT5 is honestly shown as deferred
- real broker execution remains unavailable
