Project name:
High Roll Market AI

Core product vision:
Build an AI-powered trading command center that connects to MT5, supports live trade execution, manages risk, learns from day-to-day trading behavior, finds high-probability entry windows, tracks every trade, and gives the user a professional trading calendar, journal, and AI trade manager.

The app must support:
- Forex majors
- Forex minors
- Forex exotics
- US30
- NAS100
- SPX500
- GER40
- UK100
- JP225
- U.S. stocks
- Crypto placeholders
- Volatility 75 Index
- Volatility 75 1s Index
- Volatility 25 1s Index

Important build rule:
The app must be fast enough to avoid missing trade conditions. Use efficient scanning, cached market data, background queues, lightweight calculations, and clean state management. Avoid slow page reloads, heavy unnecessary rendering, and overcomplicated loops.

Architecture:
Replit = web app, AI brain, scanner, journal, calendar, backtesting, risk manager, and signal engine.
MT5 = execution engine through EA bridge or Python bridge.
Broker account stays inside MT5.
The app sends trade commands to MT5.
MT5 sends account, order, and position updates back to the app.

Live trading:
Live trading must be supported, but locked behind:
- demo testing
- MT5 bridge connected
- API key validation
- risk manager active
- kill switch active
- user confirmation
- live mode warning
- max daily loss
- max weekly loss
- max open trades
- max lot size
- stop after losing streak

The AI should never promise profit.
The phrase “perfect entry” should be implemented as “highest-probability entry window.”
