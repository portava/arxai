Do not rebuild blindly. Inspect the current:

- admin trading controls

Goal:
Create one central Trade Action Center where users can review, confirm, track, and audit every AI-suggested or user-requested trading action.

This should make the app feel like:
AI detects the issue → AI recommends the action → user reviews → user confirms → backend validates → command queues → MT5 executes → app tracks result.

Important:
Do not auto-close trades.
Do not auto-open trades.
Do not silently modify stops.
Do not bypass backend guards.
Do not guarantee profit.
Do not expose secrets.
All demo/live execution actions require confirmation.
All live actions require explicit confirmation.

PART 4 — Backend Action Router

Build a backend Trade Action Router that turns confirmed actions into command queue items only after full guard validation.

Guard chain:
1. authenticated user
2. user owns or is attributed to the trade
3. platform trading mode allows action
4. emergency stop is false
5. user not suspended
6. routing mode resolved correctly
7. account type matches platform mode
8. risk limits pass
9. command is not duplicate
10. command is not expired
11. live disclosure accepted for live mode
12. explicit confirmation exists for live
13. audit log written
14. command queued only to resolved MT5 connection

If any guard fails:
- do not queue command
- mark action rejected
- show human-readable reason
- write audit log

PART 5 — AI Integration

Update AI so it can create trade action drafts, not execute directly.

AI can say:
- “I recommend reviewing a close.”
- “I prepared a close review ticket.”
- “Your trade is still valid, so I recommend holding.”
- “A stop move review may protect profit.”
- “A partial close review may reduce risk.”

AI cannot:
- execute without user confirmation
- bypass Trade Action Router
- hide live risk
- access another user’s trade
- expose shared master account credentials
- guarantee results

AI should answer:
- What action are you recommending?
- Why should I close?
- Why should I move my stop?
- What happens if I ignore this alert?
- What actions are pending?
- Did my close request execute?
- Why was my action rejected?
