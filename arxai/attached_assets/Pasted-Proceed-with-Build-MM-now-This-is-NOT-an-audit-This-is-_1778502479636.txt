Build MM = System Health, Audit, and Admin Control Center.

Goal:
Create a central system health, audit, and admin control center that lets the trader safely inspect the entire trading app, verify every build from AA through LL, monitor failures, review logs, validate safety rules, and control paper-only systems without enabling live trading.

The control center should answer:
- Is the full system healthy?
- Are AA through LL working?
- Are any integrations broken?
- Are any database tables missing?
- Are any endpoints failing?
- Are secrets protected?
- Is live trading still disabled?
- Is paper autopilot running safely?
- Are notifications firing?
- Are market data and broker read-only systems safe?
- What needs attention before the next paper session?

Important:
Build MM must NOT place trades.
Build MM must NOT enable live trading.
Build MM must NOT call MT5 live execution.
Build MM must NOT modify canPlaceTrades.
Build MM must NOT recommend live trading.
Build MM is health monitoring, audit logging, admin safety controls, and diagnostics only.
