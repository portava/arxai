Implement the ARX Locked Top 250 Market Universe.

Right now, users should only see the approved ARX Top 250 markets. No extra symbols, random broker symbols, unsupported markets, internal test symbols, simulator-only markets, or provider leftovers should appear in user-facing market search, scanner, chart selector, Ruby symbol picker, trade ticket, market lists, or watchlists.

Ruby must automatically understand a market when the user uses the real name, common nickname, abbreviation, broker alias, or standard symbol.

Any market that has no real data whatsoever must not be selectable by regular users until it becomes available.

Do not change live execution routing.
Do not change the MT5 bridge.
Do not weaken Risk Governor, AACI, Security Handshake, Chart Truth, Scanner Truth, or broker mapping.
Do not let simulator data make a market selectable.
Do not expose backend/internal/debug labels to regular users.

==================================================
PRIMARY PRODUCT RULE
==================================================

The only markets users should see right now are the ARX Top 250 Market Universe.

A market may appear to users only if:
1. It exists in the approved Top 250 symbol directory.
2. It has at least one real data source available, or a broker-supported mapping with active/fresh feed.
3. It is not simulator-only.
4. It is not internal/test/dev-only.
5. It has a user-safe display name.
6. Ruby can resolve aliases/nicknames to the correct symbol.

A market may be tradeable only if:
1. It is in the approved Top 250 list.
2. Broker symbol mapping is confirmed.
3. Real data exists.
4. Feed is fresh enough.
5. Chart Truth passes.
6. Scanner Truth passes if scanner-based.
7. Risk Governor passes.
8. AACI passes.
9. Security Handshake passes.
10. Bridge/account mode allows trading.

A market may be visible but disabled if:
- It is in the Top 250 list.
- It is a planned/approved ARX market.
- But the provider/broker data is currently unavailable.

Disabled user copy:
“Data not available yet.”

Do not allow selection until data becomes available.

STEP 2 — USER-FACING SYMBOL FILTER
==================================================

Create or update a helper:

getUserVisibleMarkets(context)

This must return only markets from the approved Top 250 directory.

Filter out:
- symbols not in Top 250
- simulator-only symbols
- internal/dev/test symbols
- raw broker symbols that are not mapped to approved markets
- unsupported provider leftovers
- markets with no data whatsoever unless shown as disabled
- hidden markets

Provider/broker discovery may return many symbols, but user-facing UI must intersect those results against the approved Top 250 directory.

Rule:
providerSymbols ∩ approvedTop250 = user-visible candidates

Never:
providerSymbols = user-visible list

STEP 3 — DATA AVAILABILITY GATE
==================================================

Add or update market availability resolver.

Suggested:

resolveMarketAvailability(market, context)

It should check:

- approved Top 250 membership
- provider availability
- broker symbol mapping
- MT5 quote/candle availability if present
- Deriv availability for synthetics
- TwelveData/Polygon availability for analysis feeds
- chart feed status
- last candle time
- last quote time
- aiUsable
- simulator-only status
- stale/delayed status

Return:

type MarketAvailability = {
  marketId: string;
  standardSymbol: string;
  displayName: string;
  approved: boolean;
  visible: boolean;
  selectable: boolean;
  tradeable: boolean;
  disabledReason?: string;
  dataStatus:
    | "live"
    | "fresh"
    | "delayed"
    | "stale"
    | "no_data"
    | "simulator_only"
    | "provider_missing"
    | "broker_mapping_missing";
  sourcesAvailable: string[];
  brokerMapped: boolean;
  feedFresh: boolean;
  aiUsable: boolean;
};

User selection rule:
- selectable = true only if dataStatus is live/fresh/delayed/stale with real provider data, depending on product choice
- selectable = false if no_data, simulator_only, provider_missing, or unmapped planned market
- tradeable = true only when all trade gates pass

For the user’s instruction:
Any market that has no data whatsoever must not be selectable until it becomes available.

==================================================
