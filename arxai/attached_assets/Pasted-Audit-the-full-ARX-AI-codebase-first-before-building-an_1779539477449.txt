9. Walk-Forward Testing and Backtesting

Do not train and test on the same data. Prevent lookahead bias.

Use older data for learning and newer unseen data for testing.

12. Global Learning Layer

Build or upgrade a Global Learning Layer.

ARX should learn from each trader individually while also improving the main ARX system from anonymized platform-wide learning.

Use three layers:

A. Private User Learning
Each user has a private Ruby trading profile based on their own trades, risk habits, scanner behavior, best/worst symbols, preferred sessions, setup types, SL/TP behavior, and repeated mistakes. This must stay private to that user.

B. Anonymous Group Learning
ARX studies anonymized patterns across users without exposing private account history, balances, broker data, account numbers, or personal strategies.

C. Main System Learning
Verified lessons from anonymous group learning improve Ruby’s reasoning, scanner scoring, risk warnings, setup detection, confidence scoring, trade replay, market behavior models, and global intelligence.

Do not expose one trader’s raw data to another trader. Do not copy a private strategy directly into another user’s recommendations.

Use minimum sample sizes before showing global insights so one trader cannot be identified.

Allow users/admin to control whether user data contributes to global learning.

Global learning should answer:
- Which setups work best across many users?
- Which setups fail most often?
- Which symbols are most dangerous during certain sessions?
- Which SL styles fail because they are too tight?
- Which TP styles leave money on the table?
- Which scanner signals actually worked after being shown?
- Which Ruby recommendations were correct/wrong?
- What separates winning traders from losing traders?
- Which market conditions create common mistakes?
- Which similar traders succeeded or failed in this condition?

Ruby can say:
“Across anonymous platform history, this setup performs poorly during high-impact USD news.”
“Users with similar trading profiles usually perform better waiting for confirmation here.”
“Your personal history is better than the global average on this setup.”
