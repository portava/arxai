PART 4 — INVESTOR ALLOCATION
====================================================

Investor can choose target allocation preference:

- Conservative
- Balanced
- Aggressive
- Custom

Important wording:
Do not promise guaranteed monthly returns.
Do not say “Aggressive gives X% monthly.”
Do not say “guaranteed profit.”
Do not say “risk-free.”

Use:
- target risk profile
- target allocation
- expected range if configured
- historical performance if actually available
- not guaranteed
- possible loss of capital

Strategy descriptions:

Conservative:
Lower-risk target profile, smaller exposure, prioritizes capital protection, lower target return range, lower drawdown tolerance.

Balanced:
Moderate-risk target profile, balanced exposure, moderate target return range, moderate drawdown tolerance.

Aggressive:
Higher-risk target profile, higher volatility, larger possible drawdowns, higher target return range, not guaranteed.

Custom:
Investor chooses percentage split.

Custom allocation fields:
- Conservative %
- Balanced %
- Aggressive %
- Cash Reserve %

Validation:
- total must equal 100%
- no negative percentages
- no blank invalid values
- cap aggressive allocation based on admin policy if configured
- show risk warning when aggressive allocation is selected or high

Add required disclosure acknowledgment before submitting:
“Trading involves risk, including possible loss of capital. Strategy profiles represent target risk preferences and do not guarantee returns. Past performance does not guarantee future results.”

====================================================

Default allocation change mode:
Approval Required.

Flow:

8. Investor sees status update.

Statuses:
- Draft
- Pending Approval
- Approved
- Rejected
- Active
- Superseded
