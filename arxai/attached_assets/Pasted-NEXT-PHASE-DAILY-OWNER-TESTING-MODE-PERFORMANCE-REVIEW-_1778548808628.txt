NEXT PHASE: DAILY OWNER TESTING MODE + PERFORMANCE REVIEW LOOP

Goal:
Turn the app into a daily testing system so the owner can use it repeatedly, track AI performance, capture bugs, and decide when the system is ready for MT5 connection later.

Do not add random new trading features.
Do not fake MT5 connection.
Do not place real broker orders.
Do not claim broker fills.
Do not expose secrets.
Do not block owner tester access.
Keep MT5 deferred until desktop/VPS MT5 bridge is connected later.

==================================================
1. CREATE DAILY TESTING MODE
==================================================

Create page:

/daily-testing

This should guide the owner through a daily trading-app test session.

Daily testing flow:

1. Open dashboard
2. Confirm MT5 deferred
3. Confirm simulator active
4. Confirm live chart active
5. Run market scanner
6. Review top opportunity
7. Generate AI trade idea
8. Run one demo manual simulator trade
9. Run one demo AI simulator trade
10. Submit one live tester intent
11. Start shadow mode
12. Run autopilot observe-only
13. Review journal/calendar/audit logs
14. Submit feedback or bugs
15. Generate daily test report

Each step should show:

- Start button
- Expected result
- Pass / Fail / Needs Review
- Notes
- Related logs
- Create Issue button

==================================================
4. CREATE AI IMPROVEMENT NOTES
==================================================

After each daily test, generate AI improvement notes:

- What AI did well
- What AI did poorly
- Best trade idea
- Worst trade idea
- Most common rejection reason
- Whether AI overtraded
- Whether AI respected risk
- Whether confidence scores were accurate
- What to improve next session

Example:

“AI performed best on trend-continuation setups but produced weak ideas during choppy market conditions. Tomorrow, require stronger trend score and avoid setups below 75 opportunity score.”
