MAIN UPDATE

One-click trading must work across every trading surface, but eligibility depends on bridge type:

1. Shared Bridge Users

* Admin/OWNER must explicitly allow one-click execution for each shared-bridge user before that user can arm it.
* A shared-bridge user cannot self-enable one-click unless admin/OWNER has granted them one-click permission.
* Once admin/OWNER grants the permission, the user can arm one-click themselves from the user UI.
* After the user arms it and agrees, Buy/Sell buttons across the app immediately send orders through the shared MT5 bridge/live execution path with no extra confirmation.
* Admin/OWNER must be able to revoke one-click permission for any shared-bridge user.
* If revoked, the user’s one-click armed state must immediately become inactive.

2. Own Bridge Users

* If a user is connected to their own MT5 bridge and the bridge is live/ready, the user can arm one-click trading themselves.
* They do not need admin approval to arm one-click on their own bridge unless an existing role/permission rule already requires trading permission.
* Once armed, Buy/Sell buttons across the app immediately send orders through that user’s own MT5 bridge with no extra confirmation.
* The user can disarm one-click at any time.
* If their bridge disconnects or becomes stale, one-click execution must stop sending and show the real connection blocker.

3. Admin/OWNER

* Admin/OWNER can use one-click if eligible.
* Admin/OWNER can grant/revoke shared-bridge one-click permission for users.
* Admin/OWNER can see one-click status, bridge type, permission state, armed state, source surface, order result, and audit logs.
