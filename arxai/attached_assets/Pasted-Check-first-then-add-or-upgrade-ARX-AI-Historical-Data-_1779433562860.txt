PHASE 4 — HISTORICAL COMPARISON ENGINE
Create or upgrade a HistoricalPatternAnalyzer.

For any selected symbol, it should compare current market behavior against:
- same time yesterday
- same time last week
- same time last month
- same time last year
- same weekday/session over the last several weeks
- same hour/session over recent history
- similar volatility periods
- similar trend strength periods
- similar support/resistance retests
- similar breakout/pullback/reversal setups

It should calculate:
- direction after similar setup
- average move after setup
- win/loss historical bias
- average drawdown before move
- average time to target
- volatility range
- spread behavior if available
- session behavior
- historical risk level
- confidence score based on sample size and quality

Do not overstate confidence when sample size is small.
If historical sample is weak, say so.

- timeframe

- entry zone
- suggested stop loss
- suggested take profit
- risk/reward
- lookback period
- session filter

- win rate
- average win
- average loss
- profit factor
- expected value
- sample size
- number of matching setups
- best/worst historical outcome
- similar setup results

- Win rate: 61%
