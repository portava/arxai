PART 3 — Netting vs Hedging Protection

Detect shared master account mode if possible:
- hedging
- netting
- unknown

If hedging:
- allow cleaner per-user position attribution by ticket.

If netting:
- warn admin that same-symbol trades may merge.
- prevent conflicting same-symbol multi-user trades unless admin enables aggregation mode.
- support an aggregation ledger only if safe.
- label P&L as estimated when exact ticket attribution is not possible.

Admin should see:
- account accounting mode
- attribution confidence
- same-symbol conflict warnings
- netting risk warnings
