Next phase: polish the ARX AI simple-first UI after the cleanup pass.

Before changing anything, inspect the current deployed app and active components first. Do not rebuild from scratch. Do not create duplicate pages. Reuse the existing components and only fix what is still cluttered, confusing, repeated, or poorly organized.

Goal:
Make the app feel clean and beginner-friendly while keeping every power feature available.

Focus areas:
- reduce visual clutter
- improve page hierarchy
- keep important actions near the top
- collapse advanced details
- simplify repeated badges/warnings
- make mobile screens easier to understand
- preserve all trading, scanner, Ruby, chart, risk, admin, and audit features

1. Inspect the updated UI first

Check these routes/pages:
- Cockpit/Dashboard
- Market Scanner
- Trade
- Positions
- Ruby/AI
- Risk
- Live Chart
- Admin/Live Shared
- More/Admin
- Settings
- bottom navigation
- Ruby floating assistant

For each page, identify:
- what appears above the fold on iPhone
- what feels repeated
- what should be collapsed
- what should become a tab
- what should move into Advanced
- what buttons are most important
- whether Ruby bubble or bottom nav covers content

2. Apply simple-first hierarchy

Every page should follow this order:

Top:
- compact status row
- current context, such as selected market/account/mode
- primary user action

Middle:
- Ruby explanation or main page summary
- current positions/results/readiness

Bottom:
- secondary actions
- advanced details
- diagnostics
- audit/debug info

Do not put advanced/debug/admin data above primary user actions unless the page is specifically an admin page.

3. Clean status display

Replace scattered badges with one compact row where possible:

Example:
Mode: Demo/Live/Ready/Blocked
Market: EURUSD
Ruby: Active
Account: Approved/Not Approved

Tapping or expanding this row should show the full details:
- EA heartbeat
- bridge mode
- broker/server
- server dispatch status
- kill switch
- feed status
- scanner engine
- admin/tester access
- readiness details

Do not remove any status data.

- selected market

5. Improve Trade layout

Trade should open to Quick Trade.

Above the fold should show:
- selected symbol
- volume
- Buy
- Sell

- compact status badge

Move these into Advanced:
- pending order type expansion
- buy limit/sell limit/buy stop/sell stop/stop limit
- detailed risk configuration
- broker technical data
- debug fields

Positions should have clear one-click Close buttons without being hidden.

6. Improve Ruby layout

Ruby should feel like the guide, not another settings page.

Chat tab:
- simple message area
- voice input
- text input
- small command hints

Market Read tab:
- selected market
- Ruby’s current read
- confidence
- entry/stop/target
- reason breakdown

Commands tab:
- command examples
- AI trade command permissions
- voice command state

Memory tab:
- saved chats
- user preferences
- memory controls

Hide system prompts, diagnostics, API state, and raw AI debug unless Advanced/Admin is opened.
