Goal:
Create a system where users can define, track, score, and improve their trading setups.

The AI should know:
- what setup the user is trying to trade
- whether the market matches that setup
- whether the entry is high quality or low quality
- whether the user is repeating bad setups
- which setups perform best over time
- which setups should be avoided

Important:
Do not guarantee profitable trades.
Do not auto-place trades.
Do not bypass Risk Governor.
Do not invent strategy performance.
Use only real scanner, market, trade, journal, and execution data.

PART 1 — User Strategy Playbooks

Create a Strategy Playbook system.

Each user can create trading strategies/playbooks with:

- strategy name
- description
- preferred symbols
- preferred sessions
- preferred timeframe
- setup type
- entry rules
- exit rules
- invalidation rules
- risk rules
- minimum risk/reward
- max spread allowed
- news filter preference
- preferred hold time
- example notes
- active/inactive status

Default setup templates:
- Breakout
- Pullback continuation
- Reversal
- Liquidity sweep
- Range bounce
- Trend continuation
- News avoidance setup
- Scalping setup
- Custom setup

PART 2 — Setup Quality Score

For every trade ticket or scanner opportunity, calculate a Setup Quality Score from 0–100.

Use available data:
- trend alignment
- market context
- key levels
- entry timing
- risk/reward
- stop loss placement
- take profit placement
- spread risk
- volatility risk
- news/event risk
- session context
- user strategy rules
- prior performance of this setup
- risk governor result
- data quality

Labels:
- A+ setup
- A setup
- B setup
- C setup
- Low-quality setup
- Avoid setup
- Data insufficient

The system must explain why the score was given.

PART 3 — Pre-Trade AI Checklist

Before opening a trade, show a checklist:

- Does this match your selected strategy?
- Is trend aligned?
- Is market context favorable?
- Is risk/reward acceptable?
- Is stop loss valid?
- Is lot size valid?
- Is spread acceptable?
- Is news risk acceptable?
- Is this within your daily limits?
- Are you chasing?
- Are you revenge trading?
- Is data fresh?

The trade ticket should show:
- setup score
- matched playbook
- warnings
- missing data
- AI recommendation:
  - Good to review
  - Wait for confirmation
  - Avoid trade
  - Reduce size
  - Data insufficient

Do not block unless Risk Governor blocks it. But clearly warn if setup quality is poor.

PART 7 — Scanner Integration

Scanner cards should show:

- matching strategy/playbook
- setup quality score
- setup label
- reason
- risk warning
- Ask AI
- Open Trade Review

- “A setup — pullback aligns with your trend-continuation playbook.”
- “C setup — trend is weak and news risk is high.”
- “Avoid — spread is above your rule.”

PART 8 — Trade Journal Integration

Closed trade journal entries should include:

- selected setup
- AI-detected setup
- setup quality at entry
- whether setup matched user rules
- entry quality
- exit quality
- result
- lesson learned

If the user took a low-quality setup and lost, mark it clearly:
“Loss followed a low-quality setup warning.”

If the user took an A setup and lost, mark:
“Setup was valid, but outcome failed. Review execution and exit.”

PART 9 — Admin Controls

Admin should be able to:
- view strategy system status
- view common setup performance across users without exposing private trade details
- disable risky default templates if needed
- set global risk warnings for certain setup types
- require setup selection before opening live trade if enabled
