Add a global no-internal-function-names exposure rule across the ARX AI app.

Goal:
Normal users should never see raw internal function names, tool names, API route names, backend method names, database field names, camelCase labels, stack traces, or developer/debug identifiers in the UI.

Current example:
Ruby chat showed getMyPerformanceSummary.
That should never appear to users. It should show a friendly status like:
“Ruby is reviewing your performance…”

Scope:
Apply this across the whole app, not only Ruby chat.

Audit and sanitize user-facing text in:
- Ruby chat
- Ruby voice mode
- quick suggestions
- market scanner
- trade panel
- one-click trade flow
- live trade blockers
- status badges
- error messages
- toast notifications
- loading states
- empty states
- admin approval messages shown to regular users
- scanner cards
- risk page
- dashboard/cockpit
- live chart page
- settings
- More page
- mobile overlays/modals

Do not expose names like:
- getMyPerformanceSummary
- getMarketRead
- executeTradeIntent
- validateLiveTrade
- fetchScannerData
- serverLiveExecutionEnabled
- oneClickLiveTradingEnabled
- aiInstantTradeCommandsEnabled
- liveSharedApproved
- brokerServerConfirm
- confirmedAccountNumber
- confirmedBrokerName
- confirmedServerName
- /api/trades/instant/execute
- /api/mt5/live-commands-poll
- raw endpoint names
- raw database column names
- stack traces
- JSON payloads
- camelCase function labels

Replace them with friendly user-facing copy.

Examples:
- getMyPerformanceSummary → Ruby is reviewing your performance…
- getMarketRead → Ruby is checking this market…
- executeTradeIntent → Sending trade…
- validateLiveTrade → Checking trade readiness…
- serverLiveExecutionEnabled=false → Live trading is not armed yet.
- liveSharedApproved=false → Account not approved for live shared trading.
- killSwitchActive=true → Kill switch active — new trades blocked.
- confirmedAccountNumber missing → Account confirmation is missing.
- API failed → Ruby could not complete that request. Try again.

Admin/dev exception:
Internal names may appear only inside an admin/dev-only collapsed debug drawer.
They must not appear for regular users, tester users, or public accounts.
Debug drawer must be clearly labeled:
“Developer details”
and collapsed by default.
