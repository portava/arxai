2. Pin or refresh master bridge snapshot
3. Verify EA heartbeat and version

5. Set routing to shared live
6. Set master bridge mode to live
7. Set platform mode to live
8. Confirm user approval limits
9. Release kill switch
10. Confirm ARX_LIVE_BROKER_EXECUTION_ENABLED state

12. Run command queue smoke test
13. Confirm activation summary

Verify stale queued commands cannot execute.
Allow admin to cancel stale queued commands.
Audit every stale/cancel event.
